# 📁 02_Protocols (协议层 / 城邦法典)

> **Layer 2: 核心协议 — 将真理翻译为刚性规则**
>
> 本目录是城邦四层降维投影的第二层。它的职责是将 `01_Research_Reports/` 中的客观知识，翻译为**不可违抗的刚性时间表、红线与行为准则**。

---

## 🎯 目录用途

在此存放您当前装载领域的**操作规范与调度算法**。例如：
- 学习领域：间隔重复协议、特定题型的解题标准、每日知识吞吐配额
- 工程领域：代码审查清单、部署红线、架构约束守则
- 研究领域：实验流程标准化、数据采集纪律、同行评审规则

## 📝 命名规范

建议使用以下格式：
```
protocol_<领域>_<协议名称>.md
```
示例：`protocol_math_spaced_repetition.md`

## ⚠️ 红线原则

协议一旦确立，即成为城邦的"物理定律"——不可靠意志力遵守，必须通过 Layer 3（`03_Daily_Execution/`）的物理约束来强制执行。
