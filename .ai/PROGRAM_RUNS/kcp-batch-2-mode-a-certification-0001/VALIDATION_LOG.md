## Manual algebra check of the PDE counterexample

The audit checks a SymPy identity; the reasoning itself is verified by hand here,
because the previous round's counterexample passed a machine check while being
mathematically wrong.

Claim: `u_xx + u_yy + x*y*u = 0` is linear and homogeneous but not separable.

1. Substitute `u = X(x)Y(y)`:  `X''Y + XY'' + x*y*X*Y = 0`.
2. Divide by `X*Y` (nonzero):  `X''/X + Y''/Y + x*y = 0`, i.e. `X''/X + Y''/Y = -x*y`.
3. The left side has the form `f(x) + g(y)`. For any such sum,
   `d^2/dx dy [f(x) + g(y)] = 0`.
4. The right side gives `d^2/dx dy [-x*y] = -1`.
5. `0 = -1` is false, so no separated solution of that form exists. QED

Why the previous attempt failed: for `x*y*u_xx + u_yy = 0`, dividing instead by
`X*Y*y` gives `x*X''/X + Y''/(y*Y) = 0`, which IS separated. Testing only the
quotient by `X*Y` is insufficient, because separation may first multiply through
by a nonzero factor. The audit now also checks that multiplying by x, y or x*y
does not remove the coupling in the replacement example.
