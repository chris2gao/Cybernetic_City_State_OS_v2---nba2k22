# 开发产物与文件隔离规范 v1

本规范是开发者可读入口，机器契约见
`../03_mechanisms/context_management/实现/文件布局契约_v1.yml`。

| 对象 | 路径 | tracked | registry | 处理 |
|---|---|---:|---:|---|
| 阶段方法/实现 | `01_workflow/<stage>/` | 是 | 是 | protected/versioned |
| 全局机制 | `03_mechanisms/<mechanism>/` | 是 | 是 | protected/versioned |
| boot | `02_boot/<name>/` | 是 | 是 | protected/versioned |
| loader/validator | `06_execution/<area>/<name>/` | 是 | 是 | protected/versioned |
| 活动开发设计 | `_dev/` | 是 | 是 | supersede，不抹历史 |
| 公开 run | `_runs/<run-id>/` | 耐久时是 | 否 | 按运行策略保留 |
| private/scratch | 宿主或 `_runs/<run-id>/_runtime/` | 否 | 否 | 完成后删 |
| 正式 handoff/outbox | run 明确公开路径 | 发布时是 | 否 | 耐久时保留 |

运行公开区只建立有内容的 01–07 阶段目录。任务×角色可使用
`entry/inbox/private/outbox/artifacts/audit` 分区，但 private 是运行时，不因命名获得
访问或发布保护。发布必须显式 allowlist 并做 sentinel 负测；禁止宽泛 Git 暂存和全量打包。

workspace 优先在仓库外；仓库内只允许 `_runtime/` 且必须被忽略。删除前提取耐久事实，
正式失败和残余继续保留。
