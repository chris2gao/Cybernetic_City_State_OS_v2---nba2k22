本版改问 T2a 自己答不了的三类：**内部冲突、单一来源、语料缺口**。

## 关于 NotebookLM 的用法（实测确认）

**它是双模的**：

- **源锚定**——答案不在你给的源里它就拒答，不会补一段听起来合理的推论。这是选它的理由。
- **Discover Sources**——它能用 Google 搜索自己找源并加进笔记本。

**两个模式不要混用，但要先后用。** 先受控语料问边界，再放开搜索做第二次抽样。
混着用会失去"这个结论来自哪里"的可追溯性。

**配额约束**：每个笔记本 50 个源、每天 50 次对话。T2a 引用文献很多，**必须挑**。

## 第一轮 · 受控语料

### 上传

T2a 报告本身，加上它引用的原始材料中**最核心的一批**（50 源上限内）。优先级：

1. NATO Admiralty System / AJP-2.1
2. ICD 203（美国情报界分析标准）
3. Heuer《Psychology of Intelligence Analysis》与 ACH 相关材料
4. Glaser & Strauss 理论饱和原文
5. Lincoln-Petersen / capture-recapture 方法学文献
6. PRISMA-S、GRADE、Daubert、Wigmore 各取一份代表
7. SIFT
8. Münchhausen 三难困境 / Popper 相关段落

**不要**把同一主题的多份二手综述都塞进去——它们会互相印证，制造虚假的"多来源支持"。

### 提问序列（一次一问，不要合并）

**摸清语料**

1. 这批材料涵盖了哪些不同的方法论传统？分别出自哪份材料？
2. 这些材料之间有没有互相矛盾的主张？具体是哪两处、分歧在哪？
3. **有哪些主张只出现在一份材料里，没有被其他材料印证？**

第三问最重要：**单一来源的主张不能与共识混为一谈**，需要被标出来。

**三个停止判据的交叉检验**

4. 材料中提到的"捕获-再捕获（Lincoln-Petersen）"方法，其成立需要哪些前提假设？
   哪些材料指出了这些假设被违反时会怎样？
5. "理论饱和"与"预期信息增益趋近零"这两个判据，在什么情况下会给出**相反**的结论？
   材料中有没有讨论过这种冲突？
6. 这三个判据分别适用于什么类型的检索任务？材料中有没有说明各自的边界？

第 4、5 问是本轮的核心：**T2a 把三个判据并列给出，但没说它们互相冲突时怎么办。**

**可落地与缺口**

7. 把材料中**可以直接转化为操作步骤**的内容挑出来，区分：哪些是具体动作，哪些只是原则性建议。
8. **这批材料没有回答什么？** 请对照第 4、5、6 三问指出缺口。

### 对回答的要求

- 每条结论注明来自哪份材料的哪一部分
- 材料中没有依据的，直接回答"材料中没有"，**不要补充你自己的知识**
- 不确定时说不确定，不要用措辞把不确定包装成结论

## 第二轮 · Discover Sources 做独立抽样

**第一轮全部问完并记录后再做，不要提前。**

新建一个笔记本（或清空源），用 Discover Sources 就同一主题自行搜索：

> 信息挖掘、信源评估、证据提炼的方法论；
> 特别是"何时可以停止收集信息"的可操作判据。

然后只问一个问题：

> 你找到的这些源里，有哪些方法论、框架或判据，是我此前那批材料中**没有**出现过的？
> 请逐条列出并注明来源。

### 这一轮的目的不是补充内容，是测量

把它找到的**新条目数**与 T2a 的条目数、以及两者**重合数**记下来，
用 Lincoln-Petersen 估计这个领域的总体规模：

```
N̂ ≈ (T2a 条目数 × Discover 条目数) / 重合数
覆盖率 = 已找到的 distinct 条目数 / N̂
```

**重合度高** → T2a 接近饱和，可以停。
**重合度低** → 像 T1 那样，说明两次检索分了层，各自的层内漏检无法估计。

这是把 T2a 教给我们的判据一，**立刻用在 T2a 自己身上**。
