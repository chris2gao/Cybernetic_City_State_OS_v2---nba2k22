## 这个阶段在做什么

**不是"了解这个问题"，是"找到能建立可行性的信息"。**

这个区别决定了搜什么。前者会搜到一堆关于问题的背景资料；后者搜的是
**能支撑或推翻"A 可以被实现"这个判断的依据**。

目标始终指向下一阶段的结果建模 B。搜索的终点不是知识，是**判断的依据**。

## 为什么依据比想法坚固

自己想出来的方案，其可行性只由想它的那个模型担保。
从证据推出来的方案，可行性由外部事实担保——**而且同一批证据还生成了验收测试**，
所以它同时约束了"做什么"和"怎么算做成了"。

这是本阶段在整条工作流里承重的原因：**它是唯一一处，错了会同时污染答案和验收标准。**

## 两个产出，不是一个

- **证据集**——已验证，带出处与时间序
- **可行性判断**——证据是否支持构建出满足 A 的东西。**可以是否定的，否定是发现不是失败**

外加一项长期资产：**信源清单**。建一次，服务后面所有问题。
