# 结果建模 B · schema v1

**与 A 同构：结构化对象 + 程序校验。** 校验不过就不是合法的 B。

---

## 结构

```yaml
承重命题:
  # 一句话：B 实现即 A 满足。这是整个建模的定义性关系
  type: string
  非空: true

主张:
  # B 的实质内容。每一条都必须挂依据
  type: array
  最少条目: 1
  每条:
    主张: string
    依据: array           # 证据条目 ID，**非空**
    最少依据: 1
    类型: "事实 | 推论 | 设计选择"
    # 事实   —— 证据直接支持
    # 推论   —— 从证据推出，需写明推理
    # 设计选择 —— 证据允许多种做法，我们选了一种，需写明为什么

    推理: string          # 类型为"推论"时必填
    备选: array           # 类型为"设计选择"时必填：还有哪些可选、为何不选

实现方法:
  # B 的可操作部分：具体怎么做到。没有这一节，阶段五无东西可拆、阶段四无东西可测
  type: array
  最少条目: 1
  每条:
    ID: string            # 供测试的"被测主体"引用
    方法: string          # 具体做什么
    类型: "脚本 | prompt | skill | 配置 | 文档 | 流程"
    # 类型决定怎么测，见测试 schema
    依据: array           # **非空**。这个做法依据哪条证据
    实现哪条主张: string   # 指向上面 `主张` 里的某一条。**非空**

候选与淘汰:
  # 形态分析生成了哪些候选，ACH 淘汰了哪些，为什么
  type: array
  最少条目: 2             # 只有一个候选 = 没做过生成，直接写了答案
  每条:
    候选: string
    状态: "采纳 | 淘汰"
    淘汰依据: array       # 状态为淘汰时必填：**哪条证据与它矛盾**

未被证据覆盖的部分:
  # B 里有多少是证据支撑不到、只能靠判断的
  type: array
  允许为空: true
  每条:
    部分: string
    为何无依据: string
    风险: "高 | 中 | 低"
```

## 跨字段校验

1. **每条主张的 `依据` 非空** —— 孤立主张不合法。这是本 schema 存在的首要理由
2. **`候选与淘汰` 至少两条** —— 只有一个候选说明跳过了生成阶段，
   直接写答案再补理由，那是确认偏误不是推导
3. **每条淘汰必须有 `淘汰依据`，且指向具体证据** ——
   ACH 的性质是用证据杀假设，"感觉不好"不是淘汰理由
4. **`类型: 推论` 必须有 `推理`；`类型: 设计选择` 必须有 `备选`**
5. **所有 `依据` 引用的证据 ID 必须在证据集中存在** —— 防止引用不存在的证据
6. **每条 `实现方法` 的 `实现哪条主张` 必须能在 `主张` 中找到** ——
   悬空的实现方法说明它在做 B 没主张过的事
7. **每条 `主张` 至少被一条 `实现方法` 覆盖** ——
   没有实现方法的主张是空话，到阶段五拆不出步骤

## B 的两半，与它们各自的锚

| | 是什么 | 锚在哪 | 供给谁 |
| :--- | :--- | :--- | :--- |
| **结果形态**（`承重命题` + `主张`） | 需求实现后是什么样 | A 的成功判据 | 判定"B 实现即 A 满足" |
| **实现方法** | 具体怎么做到 | 证据 | 阶段四（测什么）、阶段五（拆什么） |

**只留结果形态，阶段五无东西可拆；只留实现方法，没人能说清做完的是不是当初要的那个。**
两者都在 B 里，由证据连起来。

## 为什么强制"至少两个候选"

**只有一个候选，就没有发生过淘汰。**

而调研的结论是 ACH 的价值恰恰在淘汰——**用不一致性证据杀假设**。
只写一个候选再补上支持理由，形式上满足"主张挂依据"，
实质上是先有答案后找证据，**正是这套设计要防的那个方向**。

第 2 条校验拦的就是这个。

## 为什么保留"未被证据覆盖的部分"

**允许非空，与 A 的"未解歧义"同理：强行清零会逼出编造的依据。**

一条诚实的"这部分证据支撑不到，靠判断，风险中等"，
比一条硬凑的引用有用得多——后者会流进测试生成阶段，
而**阶段四的测试是从证据推的，硬凑的依据会生成假测试**。

这一栏是**给阶段四的警告标记**：风险高的部分，测试要格外注意它测的是什么。

## v1 不做的

- 不做 RDF / SHACL 图拓扑校验（v2）
- 不检查"依据的依据"——即证据本身是否有支撑
- 不做候选之间的相似度去重
