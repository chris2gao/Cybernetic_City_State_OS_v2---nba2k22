# 03 · 结果建模

由 A 与证据，辩证地推出 **B**——需求实现后是什么样，以及证据为何支持它。

**承重关系：B 实现即 A 满足。** B 是关于 A 的一个命题，不是摆在 A 旁边的交付物。

## 核心机制

**解题机制**——在 问题A → 信息 → 答案B 之间建立关联性。

这是这条链上认知负荷最重的一步，**由最强的模型出手**。

## 输入 / 输出

- 输入：A、证据集
- 输出：**B**，且**每条主张写明它依赖哪条证据**

## 可行性不单独断言

**若 B 能在证据上被构造出来，这个构造过程本身就是可行性论证。**

推导方向是承重的：**从证据推出 B**，不是先想好 B 再去找依据。
后者是确认偏误，前者是论证。

## 已有材料（T2 调研中已收集，留给本阶段）

| 框架 | 用途 |
| :--- | :--- |
| **ACH 竞争性假设分析** | 同时持有多个候选 B，靠**不一致性证据**淘汰而非靠支持证据选择 |
| 主观逻辑对 ACH 的演进 | 处理证据本身不确定时的假设评估 |

ACH 的核心价值在这里特别贴切：**它用证据去杀假设，而不是用证据去挑假设。**
这与"证据推出 B"是同一个方向。
