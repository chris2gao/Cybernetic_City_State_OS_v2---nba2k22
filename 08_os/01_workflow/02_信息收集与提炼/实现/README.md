# 实现

本阶段机制的实现文件。**规格在上一级 `方法论_v0.1.md`，这里放跑得起来的东西。**

## 该放什么

- 领域分析与信源枚举的可执行流程
- 信源清单本身（**长期资产，独立版本化**）
- 挖掘任务的模板与工具调用
- 交叉验证与循环报道剥离的具体做法
- 停止判定的计算——重合度、覆盖率、EIG

## 不该放什么

- 规格与理由——在上一级
- 某一次任务挖到的证据——那是 `07_content/`，不是这里
- 中间过程文件——**不注册、不保留**

## 第一版的要求

**接得上，不是好看。** 允许慢、允许手工触发、允许只覆盖主路径。

具体地说，第一版至少要能：给一个需求，产出一份信源清单，
在其上挖出证据，并给出一个可行性判断——**哪怕每一步都要人点一下。**

跑通之后才知道哪里不够用。在那之前，规格只是纸面自洽。
