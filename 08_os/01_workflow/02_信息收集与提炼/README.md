## 这个阶段在做什么

**不是“了解这个问题”，是“找到能建立可行性的信息”。**

这个区别决定了搜什么。前者会搜到关于问题的背景资料；后者搜的是能支撑或推翻“A 可以被实现”这个判断的依据。

目标始终指向下一阶段的结果建模 B。搜索的终点不是知识，是**判断的依据**。

## 两类研究问题

- **开放发现**：问“有什么”，可通过独立路线完整清单测量重合；
- **定向核实**：验证一个具体主张，看独立来源的一致、冲突与适用边界。

同一个 A 可以同时产生两类问题。捕获-再捕获只用于开放发现，不能给整轮研究统一套用。

## 为什么依据比想法坚固

自己想出来的方案，其可行性只由想它的模型担保。
从证据推出来的方案，可行性由外部事实担保；同一批证据还将供测试生成使用，所以它同时约束“做什么”和“怎么算做成了”。

这是本阶段在整条工作流里承重的原因：**它是唯一一处，错了会同时污染答案和验收标准。**

## 阶段二的耐久产物

运行的公开证据包至少包含：

- 挖掘目标、研究问题与领域；
- 内部证据和独立外部检索路线；
- 结构化证据索引；
- 可行性判断；
- 信源使用记录；
- 边界记录与停止理由。

另有一项长期资产：**信源清单**。有复用价值时独立版本化，不与本次任务的证据使用记录混为一份。
