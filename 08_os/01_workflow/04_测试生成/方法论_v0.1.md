# 测试生成 · 方法论 v0.1

由**证据**推导测试，用以验证 B 的实现是否满足需求。

**定义性规则：测试由证据推导，不由 B 推导。**
从 B 生成的测试检验 B 的自洽性；同一套推理产出两者时，**测试因构造而通过**。

设计依据来自 run-004 调研，出处见文末。

---

## 一、调研证实的核心风险，与它的解法

**风险成立**：现有测试生成方法**全部从规格生成**——BDD、需求驱动、属性测试，
输入都是内部行为描述。在本链条里规格就是 B，**因此陷入自我循环**：
只能检验 B 是否自洽，无法证明它有没有违背外部事实。

**解法**：证据到测试之间**有一步无法机械化的转换**，它有名字：

- **凭证选择（Warrant selection）**
- **指派问题（Designation Problem）**——把现实语义绑定到机器状态

两份报告独立命名同一件事，结论一致：
**描述性证据无法零干预转成规定性测试。** 必须由人判断
**哪些属性重要、如何衡量、误差容忍多少**。

## 二、这一步由人做，是责任归属不是技术妥协

**机器不能承担责任，人能。**

把"哪些属性重要"交给模型，等于把一个**没有主体可以追责**的判断放进验收链条的根部。
当验收出问题时，没有任何东西可以被问责——而这个判断恰恰决定了后面一切测试测的是什么。

所以这一步是**设计**，不是限制的将就。要求：

1. **显式记录**——谁在什么时候，基于哪条证据，选定了哪个属性、哪种度量、多大容差
2. **不可省略**——没有凭证选择记录的测试，不是合法测试
3. **可回溯**——测试失败时能查到当初为什么这样测

## 三、跨机制的通则：语义绑定处必有人

机制 3 的 ACH：framing 与最终裁定必须人做，机器只做一致性记账。
机制 4 的凭证选择：属性与度量必须人定，机器只做溯源与校验。

**两次落在同一处。** 机器能算关系、能查结构，
**不能决定"这个符号对应现实里的哪件事、重不重要"**。

这不是巧合，是同一个边界的两次显形。**其余机制设计时应主动去找自己的那一处。**

## 四、结构约束：溯源必须是形态，不是纪律

调研实证：**纯纪律性的追踪会静默衰退**——废弃链接、维护负担过重，
最终矩阵与现实脱节而无人察觉。

所以每条测试**强制携带**：

- `证据ID` —— 它从哪条证据推出
- `测量方法` —— 具体怎么测
- `凭证选择记录` —— 第二节那三项

**缺任一项即非法测试**，由程序拦截，不靠自觉。
这与机制 3 拦截孤立主张是同一招。

进一步的强制手段（v2）：CI 门禁、编译期绑定。

## 五、Daubert：筛的是方法，不是单条测试

**类比有效**，两份报告一致确认。

它原本是法官对专家证言的守门人职责，借来守**测试生成方法**的门：

| Daubert 要素 | 在这里怎么用 |
| :--- | :--- |
| 可测试性 | 这个方法本身能否被检验 |
| 同行评审 | 有无外部审视 |
| **已知错误率** | **用变异测试量化**——注入缺陷，看这套测试抓不抓得住 |
| 操作标准 | 有无受控流程 |
| 普遍接受度 | 领域内是否公认 |

**第三行是最有用的一条**：变异测试给出 Daubert 要的那个"已知错误率"，
能剔除**看着华丽但没有实质错误捕获能力的假测试**。

## 六、实现前验证：三件真能做的事

"没有实现物时测什么"——调研给出三个有实际信息价值的答案：

1. **约束可满足性（SMT / Z3）**——证明至少存在一个满足全部约束的连贯设计，
   或**提前暴露 B 自身的逻辑悖论**
2. **边界僭越审查**——拦住试图控制自己边界之外的东西的设计（"目标倒退"）。
   这一条对照 A 的 `边界` 槽位检查
3. **故障隔离基准线**——为后续物理测试失败提供责任归属的基准

第 2 条是调研给的意外收获：**B 可能悄悄假定它能控制环境里它控制不了的部分**，
而这在实现后才发现的代价很高。

## 七、FactScore：只量支撑密度，不当验收条件

**可用**：把 B 分解为原子主张，算被证据支持的比例，得到**支撑密度**。

**已知盲区，四条**：

- 高度依赖外部知识库的覆盖率
- 原子级置信度坍塌
- **召回率盲区**——只看"说了的对不对"，看不见"该说而没说"
- 会把封闭业务语境下的自洽逻辑**误判为幻觉**

第三条决定了它**不能当验收条件**：验收要问"覆盖全了吗"，
而它恰好在这一维度是盲的。

## 八、v1 不做的

- 不做 CI 门禁与编译期绑定（v2）
- 不做完整变异测试，Daubert 的错误率一栏 v1 记为 `未量化`
- 不接 SMT 求解器，可满足性检查 v1 靠人工推演
- FactScore 只作参考指标，不进校验
