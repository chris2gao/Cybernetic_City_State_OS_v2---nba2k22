原则：**理解与决策留给我们的模型，确定性工作外挂给工具。**

加粗的六项是**当前最缺、且最不确定有没有现成东西**的。

---

## 每项要问的三件事

1. **有没有开源工具或 skill 做这件事**
2. **能不能被 agent 驱动**——命令行、Python API、MCP server 都行；
   只有 GUI 的工具对我们价值很低
3. **接入成本**——依赖多重、要不要服务、能不能离线跑

第 2 条是关键筛子。**一个好用但只能人点的工具，在这条链里等于不存在。**

## 本轮的题型

**开放发现题**——问"这个领域有什么"，不是"这几件具体的东西怎么工作"。

因此：**预期低重合，捕获-再捕获适用**，两路并行是为了测量覆盖率。
（run-001、003、004 均为定向核实题，不适用；T1 是开放发现题，16 个候选重合 1 个。）
