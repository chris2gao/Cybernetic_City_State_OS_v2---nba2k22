## 安装链

- exposed executable 是 Windows symbolic link；其 target 是 pipx venv 内的
  `Scripts/check-jsonschema.exe`，两端都存在。
- `pyvenv.cfg`：CPython 3.14.6，`include-system-site-packages = false`。
- 项目/系统 Python executable 位于 pipx venv 之外；工具 package metadata 由
  venv Python 读取为 0.37.4。
- venv 聚合：686 个文件、12,360,162 字节。
- 当前依赖版本：attrs 26.1.0、certifi 2026.7.22、
  charset-normalizer 3.4.9、check-jsonschema 0.37.4、click 8.4.2、
  colorama 0.4.6、idna 3.18、jsonschema 4.26.0、
  jsonschema-specifications 2025.9.1、referencing 0.37.0、
  regress 2025.10.1、requests 2.34.2、rpds-py 2026.6.3、
  ruamel-yaml 0.19.1、urllib3 2.7.0。

以上用户专属绝对路径只保存在本机 run receipt；canonical wrapper、registry 和
长期说明均不写死该路径。
