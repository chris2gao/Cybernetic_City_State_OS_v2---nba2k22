# T12 结论

T12 关闭了个人路径 validator 的三类盲区：JSON 转义反斜杠、正斜杠写法和
Windows 路径大小写变体。`patterns.json` 现在只存分段源值与变体声明，匹配逻辑在
运行时展开，不把完整个人路径硬编码进 validator。README 也明确改写为按需
(`on-demand`) 校验器，并补充了 exit `0` 只对“已扫描、已配置、UTF-8 文本”成立的
语义边界。

`run-012` 的两个 JSON 证据已经用既有具名占位符脱敏，扩展口径下 `run-012`、`run-013`、
`run-014`、`run-015` 以及整个 `08_os/_runs` 都回到 `0` 命中；两个 JSON 仍可解析，
键结构与证据语义保留。仓库根两处命中也已给出判定并处理：`new-domain.ps1` 的默认根
路径不是功能必需字面量，改为从脚本位置推导；`未完成任务备忘录.yml` 只是说明文字残留，
已改成占位符表述。

全仓 tracked 摘要仍有 15 个历史命中，集中在 `.ai/` 与
`08_os/claude与人类的开发对话日志.md`。它们都不在本任务允许改动范围内，因此保留为
报告项，不进入本批次清理。
