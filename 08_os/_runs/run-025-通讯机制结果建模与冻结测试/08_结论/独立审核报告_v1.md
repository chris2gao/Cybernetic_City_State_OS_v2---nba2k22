## 独立结论

候选的 Git 拓扑、run 范围、结果模型先于冻结测试的提交顺序，以及冻结提交后的原冻结字节稳定性均成立。
原有机器结果证明的是 **40 条测试定义的 schema、引用和 R1–R14 覆盖计数通过**，不是 40 条未来功能测试已经执行通过。

审核发现三处会扩大声明的语义缺口，现以
`08_结论/独立审核补充门_v1.yml` 收紧，不修改原冻结提交及其字节：

1. **R6：排除 connector 不等于满足三传输成功判据。** 当前 unavailable 可以形成
   `blocked_by_unavailable_connector`，不能形成 R6 pass。connector 可用后必须补生产正负例；
   若项目决定永久缩小传输范围，必须先修订并重新确认 A v2。
2. **R8：实际差异报告不等于满足冻结阈值。** 原 T024 没有 `threshold_ref`，validator 还把阈值
   当作禁止项，因此无法证明 R8。补充门要求不可变阈值引用、可观察的 matched measurement 和
   实际满足阈值；缺失或 null 指标不得形成通过结论。
3. **R13：fixture 覆盖弱于真实任务与全部窗口。** 至少一个 `08_os` 外真实 core 任务必须完成
   端到端闭环；T7 前还必须由宿主 session/window manifest 补齐全部活动与新开窗口，不能用
   worktree/process 枚举代替 UI 会话事实。
