# Cosmic Ray 官方证据

本次只用项目官方文档和 PyPI 元数据确定外部事实：

- PyPI：<https://pypi.org/project/cosmic-ray/>。`8.4.6` wheel、release provenance、
  `Requires-Python >=3.9` 与 2026-04-02 发布记录。
- Concepts：<https://cosmic-ray.readthedocs.io/en/latest/concepts.html>。config、session、
  local/http distributor、in-place mutation、test command 与 timeout 语义。
- Tests：<https://cosmic-ray.readthedocs.io/en/latest/reference/tests.html>。官方
  `init -> exec -> dump/cr-report` 与 pytest/local 示例。

Python 3.14.4 兼容性、decorator、timeout、SQLite/session 和 local distributor 并未
从 classifier 推断，而是由 run-014 当前机器实验直接证明。官方文档声称 timeout
应视为 incompetent；8.4.6 实测却将一次 timeout 写为 killed，因此 canonical wrapper
以 raw output=`timeout` 为更强证据并 fail closed。
