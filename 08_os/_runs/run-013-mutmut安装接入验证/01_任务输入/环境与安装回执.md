- virtualenv：`/home/gk/.venvs/core-mutmut-3.6.0`
- isolation：`include-system-site-packages = false`

非交互 SSH clone 未在限时内完成，随后按任务授权使用普通本地 clone fallback，
再把 `origin` 恢复为 GitHub SSH URL。该 fallback 不改变 source commit，也未从
Windows 挂载目录运行 mutation。fallback 同时复制了一个陈旧的本地
`refs/remotes/origin/master`；它是 clone 内部历史，不是 GitHub 权威远端状态。

`mutmut --version` 在没有配置的 repository root 会先加载配置并失败；在声明
`[mutmut]` 配置的 mutation project 中返回精确的
`mutmut, version 3.6.0`。因此 wrapper 的版本门在 project 临时副本内执行。
