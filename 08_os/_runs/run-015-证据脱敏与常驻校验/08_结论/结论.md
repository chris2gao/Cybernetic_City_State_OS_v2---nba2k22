# T11 结论

run-012 与 run-013 的 76 个基线命中已用具名占位符或等价的分段构造清理，
没有删除证据；两个 JSON receipt 仍可解析，修改过的 Python 与 shell 文件通过语法门。
指定 cosmic-ray run-014 保持零命中且没有 changed path。

仓库现在具有一个按需、可配置的个人绝对路径 validator。它支持 tracked 与相对显式 base
的 changed 两种模式，正常输出 file/line/pattern/snippet，`--summary-only` 仅保留计数；
退出码 `0/1/2` 分别表示 clean、findings 和 invocation/error。负例 fixture 在运行时组装，
证明 detector 会以 exit 1 抓住假路径，而不把完整个人路径提交进仓库。

全仓 tracked 测量仍报告 8 个 allowlist 外命中：第一代或仓库根遗留 5 个，另有
`08_os/claude与人类的开发对话日志.md` 3 个。它们只报告、不清理；本任务没有不可安全
替换的 allowlist 内项目。
