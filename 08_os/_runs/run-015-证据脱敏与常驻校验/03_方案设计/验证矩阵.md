# 验证矩阵

| 声明 | 物理证据 |
| :--- | :--- |
| run-012/run-013 清理且证据形状保留 | validator scoped scan、JSON parse、Python/shell syntax |
| run-014 未被改动且仍无命中 | scoped scan、`git diff --name-only` |
| validator 能抓住负例 | runtime-assembled fixture unittest，预期 exit 1 |
| clean/hit/error 三类退出码稳定 | unittest 覆盖 0/1/2 |
| tracked 与 changed 两种候选集可用 | unittest 与候选分支 changed scan |
| 全仓遗留只报告不清理 | tracked full-repository summary-only scan |
| registry 与实现同批次 | YAML parse、registered-path existence check、同一 commit |
| diff 没有越界、二进制或个人路径 | allowlist gate、`git diff --check`、candidate validator scan |

负例 fixture 在测试运行时由不含完整路径的 segments 组装，因此既证明 detector 会失败，
又不会在提交态给 validator 制造自命中。
