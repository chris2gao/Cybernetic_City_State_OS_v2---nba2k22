## 两处这一步暴露的东西

**一、可信度 2 的源不是低价值源。** 踩坑讨论单条不可信，
但它是**唯一系统性存在失败案例的地方**——而步骤 0 的第二组问题（什么会让我们相信不能实现）
只能从这类源找到答案。

**官方文档与论文天然只报成功。** 两轴分级在这里的价值显出来了：
可靠性 C、可信度 2 的源，对某一类问题是不可替代的。合成一个分数就会把它筛掉。

**二、"术语壁垒"是一种检索限制，我原来的模板没有这一栏。**
约束求解领域与需求追问领域**几乎没有共同检索词**，
不是因为它们无关，是因为**两个领域的人不读对方的论文**。
这需要人工搭桥（手工提供跨领域检索词），不是搜索技巧问题。

→ 记为 v1 不足，模板应加"术语壁垒 / 需人工搭桥"字段。
