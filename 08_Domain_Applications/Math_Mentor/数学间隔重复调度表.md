## 💡 数学专属 5 节点复习规则

* **R1 (逻辑加固, +1 天)**：Phase A 完整三层回忆 → Phase B 定向修补 + 人话版笔记 → Phase C 1道综合推理题
* **R2 (拓扑交叉, +3 天)**：Phase A 快速两层回忆 → Phase B 修补 → Phase C 2道交叉题（一题一回复）
* **R3 (深度检索 + 大模型映射, +7 天)**：Phase A 完整三层回忆 → Phase B 修补 + 大模型映射 + 代码考核 → Phase C 1道代码实现题
* **R4 (符号封装, +14 天)**：Phase A 符号版回忆 → Phase B 修补 + 符号版笔记 → Phase C 1道符号推导题
* **R5 (底层固化, +30 天)**：Phase A 完整纯冷回忆 → Phase B 修补 → Phase C 2道高难度交叉题

### 复习优先级规则
1. **R1/R2 绝对优先**：遗忘曲线陡峭段不可错过
2. **逾期项次优先**：所有逾期未完成的复习节点必须优先处理（先还技术债）
3. **拖延项填充空位**：当活跃区任务 < 6 时，从拖延队列按序号取前 N 个（最多 3 个）
4. **同日多项**：如果同一天有多个知识点到期，按知识点编号从小到大依次执行
5. **失败补考**：复习未通过（FAILED/PARTIAL）的知识点，追加一次 +2 天补考

### 复习结果标记
* ✅ = 已完成且通过
* ⬜ = 未执行
* ⚠️ = 逾期未执行 或 执行后未通过（需补考）
