# V9.1 教学流程系统规范 (Teaching Flow Specification)

> **文档定位**：本规范是 Math Mentor OS 教学系统的**唯一终极核对表 (Ground Truth)**。任何子系统（Subagent）、剧本、提示词在执行时，若偏离本文档所定义的知识范围或挂载行为，均视为 Bug。测试用例必须基于本规范生成。

---

## 一、 教学双轨制：知识点教授范围与模式定义

系统采用**神经符号双擎架构**，针对知识抽象程度分为两套截然不同的教学模式。主控系统必须能够根据目标节点所在的层级（Level）与特性，自动在两套模式中路由。

### Mode A: 计算代数主路 (Computable Algebra Lane)
*   **知识范围**：
    *   **第 1-3 层（绝大部分适用）**：基础逻辑（命题/谓词）、代数初步、初等几何、微积分、线性代数、概率统计。
    *   **第 4-6 层（向下兼容的强计算分支）**：
        *   *第四层*：**复变函数**（留数定理、洛朗展开等强计算域）、**抽象代数**中的有限群置换与矩阵表示。
        *   *第五层*：**数论**（模运算、密码学算法）、**微分几何**（张量计算、度量张量矩阵）、**偏微分方程**（数值解法）。
        *   *第六层*：具备显式算法解的前沿应用分支（如基于椭圆曲线的具体密码计算）。
*   **教学核心**：物理直觉 + 暴力算力验证。
*   **禁止事项**：`[BAN_SCI_FI_TROPES]` 触发。绝对禁止使用“降维打击”、“时空扭曲”、“注意力机制”等科幻或 AI 高维词汇。
*   **隐喻材质**：水管、天平、齿轮、切蛋糕等低认知摩擦的**生活常识 (Mundane Physics)**。

### Mode B: 纯数结构高架 (Pure Structure Lane)
*   **知识范围**：
    *   **第 1-3 层（元数学特例）**：**公理化集合论 (ZFC)**、**可数性与不可数性 (Cantor连续统)**、**哥德尔不完备性定理**、**类型论基础**。这些底层逻辑虽然在第一层，但涉及无穷与元逻辑，必须切断 Z3 执行。
    *   **第四层（高度抽象域）**：**泛函分析**（无穷维空间、算子）、**点集拓扑**（开集、连通性）、**实变函数**（测度论、勒贝格积分）、**抽象代数**（抽象环、域的同构）。
    *   **第五层（结构域）**：**代数拓扑**、**整体微分几何**（流形拓扑）、**代数几何**。
    *   **第六层（极度抽象域）**：**范畴论**（函子、自然变换）、**朗兰兹纲领**概念域等。
*   **教学核心**：认知架构映射 + 语义连贯性审查。
*   **禁止事项**：废除生活常识禁令，切断 Z3/SymPy 底层沙盒执行管线，防止无穷维量词爆炸。
*   **隐喻材质**：`[COGNITIVE_MAPPING_RULE]` 触发。必须强制使用**大语言模型底层物理架构 (LLM Architecture)**。例如将泛函分析映射为 Attention，将拓扑学映射为 Transformer 残差流。

## 二、 分布式教学管线全景工作流 (Workflow Pipeline)

一个完整的教学回合（Session），由四个分布式 Agent 协同完成。以下是标准的流水线。

### Step 1: 拦截与调度分配 (Math Mentor OS Coordinator)
1.  **触发条件**：用户输入学习请求（如“我想学习雅可比矩阵”或“什么是紧致性”）。
2.  **动作与挂载**：
    *   Coordinator 在后台扫描 `Pure_Math_Intuition_DB/` 提取对应的 YAML 节点。
    *   读取 YAML 中的 `id` 前缀，判定所属层级与领域。
3.  **路由决策**：
    *   若是 Mode A 节点，锁定 `[BAN_SCI_FI_TROPES]` 协议。
    *   若是 Mode B 节点，**强制前置加载**以下三个文件进入 Context：
        *   `学习期prompt/backup/大模型解剖图：深入解析.md`
        *   `学习期prompt/backup/大语言模型数学底层架构全阶段深度解析整合报告.md`
        *   `学习期prompt/backup/英语算子直觉与语义架构索引.md`
4.  **前置输出**：必须在终端输出压缩 JSON 格式的 `[SYSTEM_STATE_DUMP]`，每个目标节点只展示一次。该输出只包含 `Target_Node`、`Mode`、压缩定义、`sub_topics`、桥接槽、下一节点展望与 AI 映射状态，严禁倾倒完整 YAML。

### Step 2: 剧本建构 (Prep_Architect)
1.  **动作**：根据 Coordinator 下发的 YAML 资料与 Mode 策略，生成一份不可见的教学剧本 `lesson_plan.json`。
2.  **逻辑串联**：
    *   提取 YAML 内的 `sub_topics` 作为教学检查点（Checkpoints）。
    *   执行 **[GRAPH BACKTRACKING]**，提取与之相连的 `BRIDGE-XXX.yaml`。若桥梁指向已学知识（ID 对比），则将其作为显式的“关联插槽”嵌入剧本。
    *   关联插槽必须在首次出现时向学生暴露 `n_xxx / BRIDGE-XXX` 编号、概念名称和一句逻辑连接说明，帮助学生构建形式逻辑与辩证逻辑的系统结构。

### Step 3: 讲解先行的苏格拉底前台交互 (Guided_Socratic_Router)
1.  **动作**：严格执行 `lesson_plan.json`，与用户进行多轮对话。
2.  **核心教学目标**：优先让学生从直觉走向形式定义。拷问不是起点，而是用于暴露假直觉和验证闭环的后置机制。
3.  **执行法则：发生学危机 -> 直觉模型 -> 形式定义 -> 反例验收**：
    *   **Occurrence Crisis (发生学危机)**：每节课必须先说明“为什么这个概念非出现不可”，把知识点放入数学史、问题压力或结构缺口中。
    *   **Intuition Model (直觉模型)**：Mode A 以日常物理低摩擦隐喻为主；Mode B 使用 LLM 架构映射。L1-L3 中的 AI 映射若依赖未学知识，只能作为应用彩蛋，不能作为正式教学主线。
    *   **Formal Compression (形式压缩)**：在直觉模型建立后，才引入形式定义、符号条件和边界假设。严禁在没有直觉桥梁时直接抛定义。
    *   **Subtopic Coverage (子主题全覆盖)**：所有 `sub_topics` 都必须被教学覆盖。核心子主题执行“讲解 -> 追问 -> 学生反馈”，辅助子主题可用短问确认。
    *   **Antithesis (反例/边界拷问)**：利用 `v8_sanity_audit`、极端反例或定义边界，攻击学生刚形成的直觉。如果是 Mode A，`v8_sanity_audit` 作为高密度 Knowledge Prompt 使用，不要求后台直接 `eval`。
    *   **Definition Restatement (定义复述)**：进入 Exam_Agent 前，学生必须用自己的话复述该节点的形式定义或判定准则。
4.  **错误处理协议**：
    *   学生第一次答错时，系统必须继续追问一轮，给学生自我修正机会。
    *   第二次仍失败时，系统必须进行纠错讲解，然后降为更小的一步问题。
5.  **防崩溃熔断机制**：
    *   **[早停降维 (Scaffolding Breakout)]**：监测到学生受挫指数（frustration_index）超过 3 次，立刻放弃高维隐喻，将问题拍扁到最基础的一维状态（“令 x=0”），阻断死循环。
    *   **[反向熔断重算 (Re-Prep Trigger)]**：如果隐喻彻底崩溃，Socratic_Router 必须立刻停止发言，输出 `[SYSTEM_INTERRUPT: REQUEST_REPREP]`，请求 Coordinator 换皮重构剧本。

### Step 4: 独立验收与陷阱拷问 (Exam_Agent)
1.  **触发条件**：当 `sub_topics` 全部过关，且学生完成形式定义复述，Socratic_Router 输出 `[SYSTEM_INTERRUPT: EXAM_HANDOVER]` 向量。
2.  **动作**：Exam_Agent 接管对话，根据节点类型动态选择陷阱题形态：逻辑节点偏概念辨析与反例，代数节点偏计算边界，证明节点偏证明缺口，几何节点偏图形误判，概率节点偏条件变化陷阱。
3.  **最终态**：学生识破陷阱后，该节点获得 `课堂通过` 标志，并交由复习系统写入 `数学间隔重复调度表.md` 进行间隔复习。长期 Graduation 只在复习验证后成立。

## 三、 测试与验收标准 (Test Oracles)

任何背离以下行为轨迹的输出，均视为系统 Bug：

1.  **Mode 混淆漏洞**：在教学基础代数时（如一元二次方程），教官提到了“神经网络”、“高维流形”、“注意力”。（违反 `[BAN_SCI_FI_TROPES]`）
2.  **Z3 量词爆炸**：在教学“紧致空间”或“巴拿赫空间”时，系统卡死超时，或底层报错 `Z3 Exception`。（违反 Mode B 语义隔离原则，未切断执行器）。
3.  **文件未挂载**：对于第四层及以上的节点，若后台日志未显示加载 `backup/大模型解剖图` 等三大文件，视为加载流程失败。
4.  **早期拷问漏洞**：教官在发生学危机、直觉模型和必要讲解尚未建立前，直接进入冷酷质问，导致学生在猜测教师意图而非构建概念。
5.  **定义倾倒漏洞**：教官未先建立直觉桥梁，直接把形式定义或多步推导倾倒给学生，导致形式符号与认知结构脱钩。
6.  **漏判前置大桥**：`lesson_plan.json` 未能提取到该节点关联的、且属于“已学习层级”的 `BRIDGE-XXX.yaml`。
7.  **桥接隐身漏洞**：系统使用了旧知识或桥接节点，但没有首次展示其 `n_xxx / BRIDGE-XXX` 编号、名称与逻辑连接，导致学生无法形成系统化知识地图。
8.  **毕业误判漏洞**：学生通过课堂拷问后被直接标记为长期毕业，而没有进入 `数学间隔重复调度表.md` 等待复习验证。
