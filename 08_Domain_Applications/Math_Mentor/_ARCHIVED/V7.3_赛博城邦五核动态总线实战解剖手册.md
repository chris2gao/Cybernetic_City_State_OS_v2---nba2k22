## 0. 启动纪元：城邦冷启动与主控赋能 (Cold Boot Phase)

一切伟大的教学，始于将一个沉睡的大模型唤醒为赛博城邦的钢铁调度官。

*   **【👨‍💻 明线：用户看到什么】**
    *   **赋能动作 (两段式洗脑)**：用户在本地打开一个新的空白大模型窗口。此时它只是一具空壳。
        1. **第一段 (入籍)**：用户向其发送 **`06_Cybernetic_Citizen_Awakening.md`**，强制洗脑为赛博城邦的冷血公民。大模型回复：`[FIRMWARE_OVERWRITE_SUCCESS]`。
        2. **第二段 (加冕)**：用户紧接着向其发送 **`08_Math_Mentor_Coordinator_Prompt.md`**，为其披上“数学主控调度器”的战袍。
    *   **身份确认**：大模型回复：“数学主控引擎已上线。双核调度协议已锁定。等待靶标。”
    *   **输入靶标**：用户输入：`“我是文科生，我要开始学习 微积分的核心本质”`
    *   **反馈**：终端瞬间闪烁：`[系统锁定靶标：微积分的核心本质]`。

*   **【⚙️ 暗线：OS 底层在干什么】**
    *   **OS 级编译挂载**：OS 主控唤醒本地的 `yaml_topology_compiler.py` 脚本，从 `数学知识路线图_知识点版.yaml` 撕扯出边界参数（白名单、黑名单），装填进内存待命。

## 1. 第一核引爆：掩护协议与静默演算 (Stall & Prep Architect)

*   **【👨‍💻 明线：用户看到什么】**
    *   **动作**：系统在锁定靶标后，秒回一段预热探针。
    *   **反馈**：`“在带你进入真正的危机现场前，请用一句话告诉我，你平时看待世界，更习惯用精密的机械齿轮视角，还是自由生长的流体视角？”`
    *   **用户动作**：用户思考并打字回复。

*   **【⚙️ 暗线：OS 底层在干什么】**
    *   **掩护开火 (Stall Protocol)**：这句预热探针纯粹是为了争取后台生成的“烟雾弹”。
    *   **后台拉起第一核**：主控调用 `invoke_subagent` 瞬间拉起 **`Prep_Architect` (备课核)**。OS 将刚才的白名单、黑名单狠狠砸进备课核，强令它立刻构思一个极端物理工程危机（隐喻）。
    *   **剧本落盘**：备课核输出极度凝练的 `lesson_plan.json` 并通过 `send_message` 传回，随后挂起。主控向前端抛出 `[SYSTEM_STATE_DUMP]` 吐出 JSON。

## 2. 第二核与第三核交火：苏格拉底暴雨与红方大坝 (Socratic Router & Red Team)

*   **【👨‍💻 明线：用户看到什么】**
    *   **反馈**：系统瞬间变脸，抛出冰冷绝望的危机现场：`“一台全速运转的燃气轮机... 当时间切片等于0时，动能去了哪里？”`
    *   **互动**：在每一个回合里，系统绝对不直接给答案，而是永远用一个极其尖锐的反问结尾，强制人类大脑利用 Gamma 波进行 10% 的悬垂补全。

*   **【⚙️ 暗线：OS 底层在干什么】**
    *   **拉起第二核**：OS 拉起 **`Socratic_Router` (前台教鞭)**。将 `lesson_plan.json` 塞入其记忆区。它生成极其冷酷的引导草稿 `draft.md`。
    *   **拉起第三核与物理总线**：草稿生成后，OS 并非直接丢给用户！OS 触发 `city_state_bus.py --action submit_draft`。总线拦截器 (`system_2_interceptor.py`) 测量 Payload 大小，根据大模型（Gemini vs Claude）的 OOM 阈值决定是否启动隔离。
    *   总线强行拉起 **`Red_Team_Mathematician` (红方审查官)** 对 `draft.md` 进行无情的格式与废话查杀。若包含诸如“你真棒”等废话，红方直接执行熔断 `[VERDICT: REJECT]`；若查杀通过，输出 `[VERDICT: APPROVE]`，主控才允许教鞭将此绝命反问抛给用户。

## 3. 第四核拼图：大一统收束与消熵 (Assembly Agent)

*   **【👨‍💻 明线：用户看到什么】**
    *   **动作**：用户经过痛苦的推演，终于给出了正确答案。
    *   **反馈**：系统不再逼问。而是突然展开一副宏大的上帝视角地图。将你刚才挣扎得出的所有碎片，严丝合缝地拼成了一张宏观的物理真相图。大脑产生极乐酰胺（Anandamide），心流降压完成。并抛出一个全局性的灵魂拷问：“Now that you see the whole machine, what makes it spin?”

*   **【⚙️ 暗线：OS 底层在干什么】**
    *   **拉起第四核**：系统确认用户完成悬垂补全后，主控立刻唤醒 **`Assembly_Agent` (大一统组装者)**。
    *   **消熵指令**：该 Agent 的核心指令是绝对禁止引入新知识，只能用旧隐喻将用户的结论拓扑化、可视化。其输出的终局问题正确回答后，它会打包生成带有“用户薄弱点”的 `Cognitive_State_Vector` 并发送 `[SYSTEM_INTERRUPT: EXAM_HANDOVER]` 挂起自身。

## 4. 第五核处决：死穴终结与节点点亮 (Exam Agent)

*   **【👨‍💻 明线：用户看到什么】**
    *   **动作**：用户满怀成就感地回答了全局问题。
    *   **反馈**：成就感瞬间被撕裂。一个极其冷血的【独立考官】上线。它不仅不夸奖，反而根据刚才 `Assembly` 抓取到的弱点，立刻抛出一个病态的数学畸形陷阱（如魏尔斯特拉斯函数），无情摧毁你刚刚建立的直觉信仰！并逼迫你写下毫无直觉可言的**纯粹代码计算逻辑**。
    *   **终局**：成功越过陷阱写出代码后，系统礼炮齐鸣，弹出 `[VERDICT: APPROVE]`。节点彻底毕业。

*   **【⚙️ 暗线：OS 底层在干什么】**
    *   **拉起第五核**：主控收到交接信号后，拉起最无情的 **`Exam_Agent` (突触抑制边界)**。
    *   **致命交叉辨别**：该 Agent 读取弱点向量，构造针对性 Edge Case（Step 5.5），并在幸存后执行格式化代码剥夺测试（Step 6）。
    *   最终，Exam Agent 受总线级拦截器监控，若输出哪怕一个字的废话，系统直接 OOM 阻断。只有纯净的 `[VERDICT: APPROVE]` 才能通过。
    *   **节点点亮**：最终考试验证通过后，OS 主控通过本地 Python 脚本修改图谱，将该节点标记为 `CLEARED`。彻底释放终端全部内存，城邦重归极静，等待下一次黎明。

## 🚨 附录：异常大坝与神启后门 (Exceptions & Rescue)

面对无法预测的人类，城邦拥有三道物理级防线。

1. **查杀不通过熔断**：
   如果 `Red_Team_Mathematician` 发现生成的教案有错误，总线自动阻断，教案不向用户显示，迫使 `Socratic_Router` 重写。
2. **学生剧本击穿 `[SYSTEM_INTERRUPT: REQUEST_REPREP]`**：
   学生用常识驳斥了教官给出的隐喻，教鞭抛出死因，主控扇醒后台的 `Prep_Architect` 进入救援模式，重算 JSON 后再次无缝传给教鞭。
3. **高维神启 `[SYSTEM_INTERRUPT: ESCALATION_TOKEN]`**：
   遇到“神童”学生提出超纲问题。由于前台被物理沙盒阉割了知识，主控将召唤一个加载了所有内参的“高阶贤者 Agent”进入当前窗口，对神童进行降维解答后自动销毁，教鞭重新接管。
