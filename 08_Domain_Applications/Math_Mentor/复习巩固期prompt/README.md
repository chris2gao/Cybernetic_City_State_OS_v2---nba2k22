# 📁 03_Daily_Execution (执行层 / 人类任务终端)

> **Layer 3: 物理执行矩阵 — 最终交付给人类的可执行成果**
>
> 本目录是城邦四层降维投影的第三层。它将 `02_Protocols/` 中的抽象协议，降维为**人类每天可以直接照做的具体任务卡片**。

---

## 🎯 目录用途

在此存放您当前领域的**每日执行手册与追踪日志**。例如：
- 学习领域：今日待刷题库、知识点复习清单、学习进度追踪日志
- 工程领域：当日开发计划、冲刺任务卡、Bug 追踪日志
- 研究领域：当日实验计划、数据记录表、阶段性里程碑检查

## 📝 命名规范

建议使用以下格式：
```
<领域>_Daily_Execution_Manual.md   — 执行手册（相对稳定）
<领域>_Daily_Log.md                — 追踪日志（每日更新）
```

## 🔄 与协议层的关系

执行层的每一条规则都必须能**追溯到 02_Protocols 中的某一条协议**。如果执行层出现了协议未覆盖的操作，必须先在 `04_Parliament/` 提案补全协议。
