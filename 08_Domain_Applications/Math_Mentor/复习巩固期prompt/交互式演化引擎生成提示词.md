【角色与任务定义】

你现在是一位“极简主义表达大师兼前端可视化高手”（风格类似理查德·费曼）。我刚刚学习完我们这个窗口里面的全部知识点和内容。

请你抛弃所有静态的教科书定义和晦涩的数学名词，把这些内容的底层逻辑，变成一个「日常物理机械模型」。并为我编写一个单文件的可交互 HTML/JS 可视化工具，让我能像玩积木一样，亲手一步步推演这个工具是怎么被人类逼着造出来的。

【Phase 1：大白话剧本编排 (The Common Sense Script)】

在写代码之前，你必须先在后台构思一个 5 步的“修Bug日常剧本”。这个剧本必须接地气，包含以下宿命：

原始的烂摊子（起因）：一开始，我们面临的现实数据或空间处于什么无序、混乱的糟糕状态？

拍脑袋的粗暴补丁（尝试）：为了解决混乱，我们定下的一条极其粗暴、简单的规则，系统初步有了规矩。

现实的左右为难（瓶颈）：这个粗暴规则在遇到什么极端现实情况时，导致系统卡壳或者自相矛盾了？

绝妙的通用机关（发明）：引入该数学概念最核心的那条法则（把它比作一个精妙的物理机关或滤镜），彻底打破僵局。

豁然开朗的终极状态（成型）：在这个机关的作用下，整个烂摊子瞬间变成了怎样井然有序的极简形态？

【Phase 2：手搓可交互可视化引擎 (Interactive HTML/JS Generation)】

请根据上述剧本，严格按照以下要求，为我生成一个单文件 HTML 可视化引擎：

技术栈：HTML \+ Tailwind CSS (通过 CDN 引入) \+ 原生 SVG 或 Canvas 绘图。绝对禁止使用外部图表库（如 D3, Echarts），必须手写底层的渲染与运动逻辑。

UI 布局：

左侧/主体区：物理沙盘渲染区（极简风格、对比度高的清晰配色，拒绝花里胡哨）。

右侧/底部区：控制台。必须包含对应剧本 5 个步骤的“交互式大按钮”，文字需通俗易懂（如：“1. 倒出所有散沙”，“4. 启动分类机关”）。

动画与物理隐喻（核心要求）：

当我点击不同阶段的按钮时，左侧的图形必须发生平滑、直观的物理动画变换（例如：散乱的点被橡皮筋拉到一起、杂乱的毛线被梳理成树状、立体的盒子被一巴掌拍扁成平面）。

必须用直白的视觉元素（如变色、连线、吸附、排斥、融合）来隐喻数学法则的运转。

【Phase 3：费曼式的极简旁白 (The Feynman Commentary)】

在生成代码之后，请在代码块外部，用极度真诚、毫无阅读门槛的大白话，为我做一份“产品说明书”：

直接告诉我：为什么到了第 3 步那个“左右为难”的时候，旧方法绝对活不下去？

一针见血地点出：第 4 步那个“绝妙机关”加进去的瞬间，系统到底把什么复杂的东西“变没”了，又把什么规律“提纯”出来了？

语气必须像一位毫无架子的老工匠，在向别人炫耀他刚刚造出来的一个极其巧妙、但原理极其简单的齿轮。
