# Callback registration and rotation discovery checkpoint

The full M0–M5 objective remains active. This checkpoint supplies one new deferred Native minute action and reusable bounded static discovery tools; it does not close Playbook, staff, player editing or the whole Coach surface.

`tools/recover_script_callbacks.py` joins an ASCII declaration to the exact decoded registration template `xor r9d,r9d; lea r8,callback; lea rdx,declaration; mov rcx,rbx; call0x1fbaf0`. It reports query/selection limits, actual instruction windows, callback candidates and their unwind chains. Other registration templates are out of scope. `tools/recover_entry_windows.py` records bounded leaf/thunk windows without pretending that a window is an entire function or ABI. Both inspect the pinned PE only.

The evidence progresses from declaration → decoded caller → native field effect → delegate slot join → context/ABI → explicit argument contract → handler/compiler/role mapping. A declaration or JSON verification alone never completes those stages.

The callback tests decode actual synthetic x64 instruction bytes, including a following TEST to guard against the original window error. Wrong registration target, noncode callback and selection truncation are tested without opening the game. No Ghidra whole-game import was retried, no process was attached, and no game state changed.
