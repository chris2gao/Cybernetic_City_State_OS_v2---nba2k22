## 第一章：NBA 2K22 战术底层机制与核心公理

### 1.1 战术的原生底层结构（彻底破除黑盒）
在 NBA 2K22 游戏引擎中，每条战术均由一个 72 字节（`0x48`）的 `PLAY_DEFINITION` 结构体定义，核心决定字段如下：
1. **唯一主分类（`+0x26` 高 5 位，`fb[2] >> 3`）**：每条正式战术在底层**唯一属于 1 个主分类（Category 1–12）**，与游戏 UI 战术手册添加/替换菜单中的 12 个中文类别一一对应。
2. **5 位位置允许掩码（`+0x27` 低 5 位，`fb[3] & 0x1F`）**：用 5 个 bit 精确规定球场上 `1–5` 号位（PG/SG/SF/PF/C）中哪些位置有资格发起或触发该战术。`0x1F` 表示 1–5 号位通用，而如 `'71 PUNCH 13` 为 `0x05`（仅 1、3 号位）。
3. **战术名称（UTF-16LE 指针）与唯一 CRC32**：同一条战术 CRC 可被多支球队的 `PLAYBOOKDATA`（68 槽）共同引用。

### 1.2 六条不可违背的设计公理

1. **公理一：阵容与球员优势为第一根基（Roster-First Principle）**
   - 交易是确定性的、阵容相对固定（一年仅调整一次）。**绝不为了套用某个死板体系而强行修改或委屈球员**，而是**以当前阵容与核心球员的天赋、射程、传控、运动能力、背身为最高优先级**，反过来挑选最能释放这些优势的体系（Freelance）与战术（Plays）。教练体系同源性（如 `PACE`、`TRI`、`FLOW`）仅作次级加分项。
2. **公理二：`PlayType` 是可配置的“执行开关”，而非前置门槛（附 2K22 枚举实机修正）**
   - 我们具备原生修改球员 4 个有序 `PlayType` 槽位（`PLAYER_SET_PLAY_TYPES_1_TO_4`）的能力。如果某球员非常适合执行某类战术，直接为他配置对应的 `PlayType` 即可（**第 1、2 槽为主用、执行频繁；第 3、4 槽为辅助/偶尔触发**）。
   - **重要实机修正（2026-11-26 实测）**：在 NBA 2K22 PC 引擎中，**`14` 才是真正的“三分 / 外线投篮 (3 PT)”**（库里、克莱、邓罗均使用 `14`），而早期文档写的 **`15` 在游戏界面中显示为空/无效**；此外，向手册中写入战术时必须限定 **`in_ui_playbook_pool == true`（1,300 条实机可见可用战术）**，禁止选入 `5OUT BIG TOP` 等 Freelance 内部隐藏动作，且 `Regular + Bench` 主列表可见上限为 42 条、`Endgame` 末段战术不占主列表显示。
3. **公理三：年代空间公理与淘汰铁律（Era Spacing Law）**
   - **现代无年代标识战术（1,880 条）**：**主力战术库**。外线站位天然拉开到三分线外（含大量 `5OUT` / `SPREAD`），完美适配现代 2K 引擎的高效空间与三分能力。
   - **80 年代以前（`'60`–`'79`，78 条）**：**全部淘汰不用**。站位极度缩在三分线内，严重堵塞突破和外线空间。
   - **80–10 年代（`'80`–`'19`，432 条）**：**慎用 / 备用选择**。年代越早站位越紧凑，`'90`/`'00`/`'10` 仅在某条战术极度契合核心球员（如传统双塔或经典三角低位）且确认不严重堵空间时才考虑选用。
4. **公理四：威胁、博弈与“第二/第三执行点”本质**
   - 战术不是必须死板跑完的剧本，而是一个**“制造核心威胁、释放优势面”**的起手计划。
   - 控球手在跑战术过程中，会结合 `Play Discipline`（战术纪律）与防守反应（包夹/换防/协防）实时阅读：一旦弱侧或掩护点出现空位，持球人会直接跳出预设轨迹出球给第二、第三选择（例如奥尼尔低位吸引包夹后外线射手的空位、双探花多点挡拆跑出的三分空位）。
5. **公理五：中投类的极简节制原则**
   - **挡拆外弹中投（Cat 3）**与**中投（Cat 11）**：普通现代球队**不设或最多只配 1 条**（排除 `HHD` 等冷门系列）。仅当球队拥有**历史级中投大师**（杜兰特、德罗赞、布克、保罗、小卡、SGA）或无三分中投内线时，才专门配置 **1–3 条**作为破三分铁壳的稳健手段。
6. **公理六：手递手与动态连接的高价值性**
   - 现代篮球不再靠单一持球人硬凿，通过 `GIVE`（手递手）、`HORNS`（牛角）、`SHORT`（短顺下）、`STS`（连环掩护）把大个策应与射手跑位串联起来，是破解名人堂高强度对位防守的核心密码。

## 第三章：NBA 2K22 战术命名语法与高频词根全词典

看到任何一条战术名字时，按 **`[年代] + [动作前缀] + [位置/体系代号] + [阵型/掩护/变化词根]`** 四段式直接解码（注：前缀 `W` 可忽略，直接看后面的词根）：

### 3.1 动作前缀（决定主分类骨架）
* **`FIST`**：挡拆系（Pick & Roll / Pop / Option）
* **`QUICK`**：无球掩护投篮系（3PT / Mid-Range）
* **`PUNCH`**：背身单打系（低位 / 高位 / 后卫背身）
* **`GIVE`**：手递手系（DHO / Give & Go）
* **`ISO`**：单打系（Isolation）
* **`CUT`**：空切系（Cutter / Alley-Oop）
* **`HIGH`**：高位肘区策应/背身系
* **`FLOPPY`**：双底线兜出无球掩护三分

### 3.2 位置编号规则
* **两位 `1–5` 数字**（如 `15`、`25`、`14`、`32`）：第一位通常代表持球/发起或主攻位置，第二位代表掩护/配合/接应位置（如 `FIST 15` = 1号位持球 + 5号位掩护；`FIST 14 POP` = 1号位持球 + 4号位外弹；`PUNCH 25` = 2号位喂球 + 5号位低位）。
* **两位 `6X/7X/8X/9X` 数字**（如 `71`、`81`、`91`、`62`）：2K 历史传承的战术系列代号（非 6–9 号位），常搭配 `1`/`2` 表示给后场发起的特定跑位路线，使用时以其实机原生分类与 `allowed_positions` 掩码为准。

### 3.3 高频空间、落位与变化词根词典
* **空间与落位词根**：
  * **`5OUT` / `SPREAD`**：五外 / 四外一内极度拉开空间，彻底清空禁区。
  * **`HORNS`**：牛角阵型（双内线站左右肘区、双射手站底角），容错率极高、双侧均可发牌。
  * **`ELBOW` / `PINCH`**：肘区（罚球线两角）单侧发牌与策应连接。
  * **`TOP` / `WING` / `SIDE` / `CNR` (CORNER)**：明确指定战术发起在弧顶 / 45度侧翼 / 边路 / 底角。
  * **`BOX` / `"1-4"`**：盒子阵型 / 1-4 高位或低位一字排开落位。
* **掩护与终结变化词根**：
  * **`POP` / `PNF`**：掩护后外弹接球投篮（区别在 Cat 3 中投 vs Cat 4 三分）。
  * **`SHORT`**：短顺下（停在罚球线 4v3 二次发牌），**专破上线包夹**。
  * **`SLIP`**：假掩护直接滑切顺下，**专克无限换防与激进夹击**。
  * **`STS` (Screen-the-Screener)**：连环掩护（为掩护人再做一次掩护），双核心/多射手球队杀招。
  * **`HAMMER`**：底角锤子掩护（强侧突破吸防，弱侧底角横挡送空位三分）。
  * **`FLARE`**：向外外弹无球掩护（防追身绕过）。
  * **`RIP`**：底线/背向掩护直插篮下（极易制造错位深位或空接）。
  * **`PIN` / `PINDOWN`**：垂直向下掩护（助射手从底线兜出到 45 度/弧顶接球投）。
  * **`ZIP`**：Zipper cut（底线借中锋垂直掩护上提至弧顶接球）。
  * **`IVERSON` / `AI`**：艾弗森横切（从弱侧横穿罚球线借双高位掩护接球）。
  * **`CURL` / `LOOP`**：绕掩护卷切往篮下/罚球线，或底线绕大圈跑位。
  * **`ALLEY` / `DIVE`**：空中接力 / 强力空切下顺。
  * **`SERIES` / `TWIST` / `ANGLE`**：连续系列多选择 / 改角度再掩护。
  * **`DRAG` / `EARLY` / `DELAY`**：转换追身拖车挡拆 / 早攻推进 / 拖车中锋高位策应。
* **体系同源词根（可直接对照球队风格筛选）**：
  * **`PACE`**（Pace & Space 五外空间）、**`FLOW` / `WARRIOR`**（勇士动态传切）、**`TRI`**（三角进攻，多含中距离/背身串联）、**`SWING` / `SLICE` / `HAWK` / `FLIP` / `EIGHTY`**（对应同名 Freelance 体系动作库）、**`PROC` / `JOKER` / `NASH`**（特定巨星/球队招牌模型）。

## 第五章：球队 68 槽战术手册设计标准 SOP

当拿到任何一支确定阵容的球队（10 人左右主轮换）时，按以下步骤从零组装这支球队的 **68 槽 `PLAYBOOKDATA`**（常规 30 槽 + 替补 20 槽 + 末段 10 槽 + 收藏 8 槽）：

### Step 1：盘点阵容核心资产（明确“我是谁”）
1. 列出全队前 3 号持球/终结威胁点（谁吸防？谁单打？谁错位？）。
2. 统计场上常态空间射手数量（3 分 ≥ 78 的人数：决定用 `5OUT`/`SPREAD` 还是 `HORNS`/`4-OUT-1-IN`）。
3. 判定内线属性：吃饼型 / 外弹三分型 / 高位发牌型 / 真低位型。

### Step 2：配比 **常规战术槽（Slots 0–29，共 30 槽）**
按阵容特征分配 30 个槽位的配额（以现代主流球队为例）：
* **主力挡拆与挡拆选项（8–12 槽）**：
  - 持球大核多 → 多配 **Cat 5 (`HORNS`/`5OUT`/`SHORT`/`STS`)**；
  - 有空间内线 → 必配 2–3 条 **Cat 4 (`POP CNR`/`POP`)**；
  - 有吃饼怪 → 配 3–4 条 **Cat 2 (`SLIP`/`DIVE`)**；
  - 外弹中投（Cat 3）→ **0–1 槽**。
* **三分无球战术（6–10 槽）**：
  - 必须覆盖主力射手的接球习惯：如 `FLOPPY`、`FLARE`、`HAMMER`、`IVERSON`、`STS`。
* **手递手与切入（4–6 槽）**：
  - 有策应内线必配 3–4 条 **Cat 10 (`GIVE...FIST`/`ELBOW`/`5OUT`)** + 2 条 **Cat 9 (`CUT ALLEY`/`UCLA`)**。
* **背身与单打硬解（3–6 槽）**：
  - 顶级单挑/锋卫背身（如双探花/东契奇/布克）→ 配 2–3 条 **Cat 1 (`ISO 5OUT`)** + 2–3 条 **Cat 8 (`PUNCH ZIP/SLICE`)**；
  - 真低位中锋（如恩比德/约基奇）→ 配 3–4 条 **Cat 6 (`PUNCH 5OUT`/`RIP HAMMER`)** + 1–2 条 **Cat 7 (`HIGH`)**；无低位中锋则 Cat 6 配 **0 条**。
* **中投（Cat 11）**：普通队 **0–1 槽**；中投超巨队 **2–3 槽**。

### Step 3：配比 **替补战术槽（Slots 30–49，共 20 槽）**
* **原则**：替补阵容往往缺少顶级持球大核或全员五外投射，**切忌照搬需要高球商和超巨单挑的复杂战术**。
* **优先配置**：简明直接的 **Cat 2 挡拆（`FIST 15` / `SLIP`）**、**Cat 12 简单下掩护三分（`FLOPPY` / `PIN`）**、**Cat 10 手递手（`GIVE`）** 以及针对替补席某位单打第六人（如克拉克森/蒙克/希罗）的 1–2 条 `ISO`/`PUNCH`。

### Step 4：配比 **末段关键球槽（Slots 50–59，共 10 槽）**
* **原则**：关键时刻防守强度极高、无限换防盛行，**必须配容错率最高、最不容易被包夹/抢断失误的战术**！
* **黄金组合**：
  1. **3–4 条清空强侧的单打/错位背打**：`ISO 5OUT`、`PUNCH ... HAMMER`（大核点名最弱防守人）；
  2. **3–4 条破换防/破夹击挡拆**：`FIST ... SLIP`（假掩护顺下）、`FIST ... SHORT`（短顺下 4v3）、`FIST ... STS`（双核连环掩护，如库里+格林、双探花相互掩护）；
  3. **2 条快打空位三分 / 绝杀战术**：`QUICK ... HAMMER` 或 Cat 16 `QUICK LAST SECOND "3"`。

### Step 5：校验硬件一致性（最后一步闭环）
1. **检查位置掩码**：确保战术的 `allowed_positions` 覆盖了你想用来发起该战术的球员所在位置。
2. **同步球员 `PlayType`**：根据上述配好的战术库，反手将球队核心轮换球员的 1–4 号 `PlayType` 槽位设置对齐（最重要、占比最高的战术类型放第 1、2 槽）。
3. **校准 `RunPlayTendency` 与 `Play Discipline`**：跑复杂连环战术的纪律型球队（勇士/凯尔特人/掘金/热火）适当提高战术执行率与球员战术纪律；强单挑型球队则留出自由发挥空间。
