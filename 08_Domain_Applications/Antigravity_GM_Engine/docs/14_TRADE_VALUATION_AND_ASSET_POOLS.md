本文档系统规范了 Antigravity 外部 GM 引擎在 **“五维球员资产池与制服组资产池管理”**、**“动态交易价值评估模型 (0~10,000 点数值体系)”**、**“两大老板基于生命周期的主观博弈与双赢撮合公式”** 以及 **“交易五大否决红线 (Deal Breakers / 为什么谈不拢)”** 上的完整底层逻辑与实机执行标准。

## 一、为什么需要外部交易系统？（游戏痛点与核心宗旨）

在 2K 原生模式中，游戏自身的 CPU 交易逻辑极度混乱（经常出现多名后卫扎堆、轻易贱卖年轻核心、或者给平庸老将开出顶薪锁死薪资）。为了保证 2022~2026 拟真大迁徙的科学与严肃性：
1. **游戏原生 CPU 交易已在内存中永久关闭 (`CPU_CPU_TRADE = 0`)**；
2. **所有联盟交易一律由外部 GM 引擎根据客观价值、老板诉求与劳资协议多方推演，达成一致后通过内存热写入生效**。

```
     ▼                                                                 ▼

· 自由球员池 (Free Agents: 底薪老将/双向新人)                      · 助理教练池 (战术熟练度与针对性防守)
· 货架筹码池 (Trade Block: 摆上货架的到期约/冗余)                   · 首席训练师池 (A+/A/B 级，掌控原生属性成长速度)

· 选秀权资产库 (Draft Picks Inventory: 2022~2027 首/次轮)          · 商业总监/CFO池 (门票运营与合同谈判)
```

### 1. 球员资产分级标签库 (Roster Player Tiers)
每支球队在册球员必须严格被打上以下 6 大标签之一：
1. **Tier 0：世代级超巨非卖品 (Untouchable Eternal)**：如迈克尔·乔丹、斯蒂芬·库里、勒布朗·詹姆斯、约基奇、东契奇、字母哥、以及玩家 MC 球员哈利伯顿。**一票否决，绝不可交易！**
2. **Tier 1：核心基石 (Core 1 & Core 2)**：各队战术轴心（如塔图姆/布朗、恩比德/马克西、莫兰特/小贾伦），仅在触发不可抗力（超巨申请离队）时换取历史级倾囊筹码；
3. **Tier 2：潜力新星 / 学员 (Rising Star / Mentee)**：23 岁以下高潜新人（如康宁汉姆、格林、申京、瓦格纳），重建队的核心命根；
4. **Tier 3：老将导师 (Veteran Mentor)**：拥有黄金徽章与职业素养的更衣室导师（如伊戈达拉、霍福德、亚当斯、戈登）；
5. **Tier 4：轮换战术拼图 (Tradeable Pieces)**：优质 3&D 侧翼、护框替补、射手，日常交易的主要流通筹码；
6. **Tier 5：到期薪资配平包 (Salary Fillers / Expiring)**：到期合同或高薪低能死钱，专用于配平薪金或搭配选秀权清理。

## 三、动态交易价值评估模型 (Dynamic Trade Value Formula)

外部 GM 引擎采用客观多维点数模型，对任何一位球员进行精确量化评估：

$$V_{\text{base}} = V_{\text{ability}} + V_{\text{potential}} + V_{\text{contract\_surplus}}$$

### 1. 即战力分 ($V_{\text{ability}}$)
* **计算逻辑**：基于 2K 游戏内综合评分 (OVR) 呈指数级拉升，同时结合年龄衰减：
  * $\text{OVR} \ge 95$：$8,000 + (\text{OVR} - 95) \times 450$ 点（天神档）
  * $\text{OVR } 90\sim 94$：$6,000 + (\text{OVR} - 90) \times 400$ 点（全明星当家）
  * $\text{OVR } 85\sim 89$：$4,000 + (\text{OVR} - 85) \times 400$ 点（高阶主力）
  * $\text{OVR } 80\sim 84$：$2,400 + (\text{OVR} - 80) \times 320$ 点（优质首发）
  * $\text{OVR } 75\sim 79$：$1,200 + (\text{OVR} - 75) \times 240$ 点（合格轮换）
  * $\text{OVR } < 75$：$\max(200, (\text{OVR} - 65) \times 100)$ 点
* **老将年龄折旧**：若 $\text{Age} > 31$，即战力分逐年折旧：
  $$V_{\text{ability}} = V_{\text{ability}} \times \max\big(0.40, 1.0 - (\text{Age} - 31) \times 0.10\big)$$

### 2. 潜力溢价分 ($V_{\text{potential}}$)
* 若球员处于 **23 岁及以下**，且 $\text{Potential} > \text{OVR}$：
  $$V_{\text{potential}} = (\text{Potential} - \text{OVR}) \times 110 \times \left(1.0 + \frac{24 - \text{Age}}{8}\right)$$
* *案例*：20 岁、评分 76、潜力 90 的新秀，单项潜力附加分即高达 **1,848 点**！

### 3. 合同性价比与到期红利 ($V_{\text{contract\_surplus}}$)
* **童工合同红利**：年轻球员年薪远低于其市场产出时，赋予 **+500 ~ +1,500 点** 正向溢价；
* **到期合同红利**：最后一年合同，为志在明夏腾空间的球队提供 **+400 ~ +800 点** 灵活红利；
* **溢价垃圾长约惩罚**：年薪严重超标且剩余年限 $\ge 2$ 年的死钱合同，扣除 **-1,500 ~ -2,500 点**！必须搭配首轮签方能倒贴送出。

## 四、两大老板博弈与双赢撮合机制 (The Win-Win Equilibrium)

### 1. 球队四大生命周期主观放大器 ($M_{\text{lifecycle}}$)
这就是为什么“两支球队能达成共识”的关键机制——**价值的不对称性产生交易盈余**：

| 生命周期阶段 | 即战力老将乘数 | 年轻高潜新秀乘数 | 首轮选秀权乘数 | 到期合同乘数 | 交易核心诉求与动机 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **争冠冲刺期 (CONTENDING)**<br>(勇士、湖人、雄鹿、凯尔特人) | **$1.40\times$** (极度看重) | $0.80\times$ | $0.65\times$ (愿送首轮) | $0.60\times$ (不愿省钱) | 倾囊出击未来资产，换取契合主帅体系的优质拼图，抓住当家巅峰期。 |
| **彻底重建期 (REBUILDING)**<br>(雷霆、马刺、魔术、火箭、活塞) | **$0.40\times$** (老将大幅贬值) | **$1.85\times$** (极度饥渴) | **$1.60\times$** (选秀权至上) | **$1.50\times$** (吃死钱换签) | 甩卖 28 岁以上老将，吃进到期垃圾合同，疯狂积累首轮签与年轻彩票。 |
| **季后赛黑马/上升期 (PLAYOFF_RISING)**<br>(灰熊、骑士、森林狼、独行侠) | $1.15\times$ | $1.25\times$ | $1.00\times$ | $0.90\times$ | 精准对位补强弱点位置，不盲目透支未来。 |
| **平庸泥潭/纠结期 (TREADMILL_RETOOL)**<br>(奇才、开拓者、公牛、步行者初期) | $0.90\times$ | $1.20\times$ | $1.30\times$ | $1.20\times$ | 观望战绩：连败则抛售老将，连胜则小修小补冲附加赛。 |

### 2. 交易敲定的充要条件：双赢不等式
一笔交易被双方老板盖章批准的充要条件：

$$\text{NetGain}_A = \sum_{\text{in}} V_A - \sum_{\text{out}} V_A \ge -300$$
$$\text{NetGain}_B = \sum_{\text{in}} V_B - \sum_{\text{out}} V_B \ge -300$$

* **真实经典案例验算（2022 年哈利伯顿换小萨博尼斯）**：
  * **萨克拉门托国王（急需打破 16 年荒，PLAYOFF_RISING 上升期）**：
    * 获得小萨博尼斯（全明星内线策应大核）：国王主观评估值 **7,800 点**；
    * 送出哈利伯顿（潜力虽高但与福克斯球权冲突）：国王主观评估值 **6,500 点**；
    * 国王主观净收益：$\text{NetGain}_{\text{SAC}} = +1,300$ 点！拉纳戴夫毫不犹豫拍板！
  * **印第安纳步行者（西蒙家族决定推倒重建，REBUILDING 重建期）**：
    * 获得哈利伯顿（21 岁传控之神，长线建队基石）：重建乘数 $1.85\times$ 放大后，主观评估值 **8,200 点**；
    * 送出小萨博尼斯（无法带领平庸阵容走远）：步行者主观评估值 **6,800 点**；
    * 步行者主观净收益：$\text{NetGain}_{\text{IND}} = +1,400$ 点！卡莱尔全力背书！
  * **结果**：双方主观收益均为巨大正数，一笔载入史册的双赢世纪交易正式诞生！

## 五、Deal Breakers：为什么有的交易谈不拢？（五大否决红线）

在外部 GM 引擎中，一旦触发以下 5 大红线之一，交易提议将被**直接否决并终止谈判**：

1. **绝对非卖品触发 (Untouchable Veto)**：
   * 任何企图交易 Tier 0 世代超巨（如乔丹、库里、约基奇、哈利伯顿）或 Tier 1 当家双核的常规提议，老板直接挂断电话；
2. **CBA 劳资协议硬配平违规 (CBA Financial Breach)**：
   * 双方送出的薪资差额超出 **$125\% + \$100,000$** 浮动范围；或让已经触发硬帽的球队薪资超标；
3. **毒药合同缺乏补偿 (Uncompensated Poison Pill)**：
   * 强队企图向重建队倾倒剩余 2 年以上、年薪超 2000 万的死钱合同，但拒绝附赠高顺位首轮签（补偿点数不足）；
4. **战术位置严重冗余 (Positional Redundancy)**：
   * 若某队已有两位全明星中锋，对方企图再塞入第三位首发中锋，该球员在该队体系中的评估值将遭受 **$50\%$ 严重惩罚折价**；
5. **同赛区宿敌税 (Rivalry Tax)**：
   * 丹尼·安吉（爵士）与佩林卡（湖人）交易，或凯尔特人与 76 人交易，主动发起方必须额外承担 **$+25\%$ 的“宿敌溢价”** 才能达成一致！
