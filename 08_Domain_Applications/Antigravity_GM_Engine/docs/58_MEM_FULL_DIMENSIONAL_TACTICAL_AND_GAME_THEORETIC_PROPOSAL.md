   * 贝恩拥有 87 三分与顶尖射术（Catch&Shoot 金, CornerSpecialist 银, Sniper），触球调升至 `68`。绑定战术 `[Screen 3PT (14), Handoff Receiver (12), P&R Ball Handler (4), Cutter (11)]`。借亚当斯扎实的掩护，贝恩既能手递手干拔三分，又能利用防守外扑完成二次突破。
