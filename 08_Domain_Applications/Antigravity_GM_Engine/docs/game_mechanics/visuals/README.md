# NBA2K图文攻略与截图证据政策

图文帮助应作为**可审查游戏机制证据**，不是把网上所有图片全搬进GitHub。

## 什么时候需要截图
当文字指南无法交代完整菜单、类别/合法枚举、选项数值、实际操作步骤、数据列或战术动作预览时，才收录视觉材料；可优先查询截图所在的官方说明或玩家攻略网页。

## 证据来源与权利
- **源网页索引（默认）**：保留原始网页URL、作者/网站、游戏版本、网页中图的位置、图中的可见事实、链接存活状态和引用的机制卡，不把第三方图像二进制复制进公开仓库。
- **用户自供实机截图**：可以在玩家允许的项目资料使用范围内保存于`visuals/approved/`，需标注当前游戏版本、UI页和操作状态，避免把临时画面错认成普遍菜单。
- **明确授权/许可再发布的图片**：保留图片许可或授权出处、图片文件原出处和作者署名；尊重截图平台及攻略网站的条款。
- **第三方版权未明的图片**：不要去水印、不要抓取后擅自公开再分发。仍可写来源页和图片索引供研究模型/用户原网页查看。
- **视频或动图**：记录真实可访问URL、具体时间戳和在该时刻可见的游戏步骤。无法读取画面时不要臆测动画轨迹；游戏的2D战术板可由截图/玩家描述定位，但不能自动认定获得动画脚本或3D执行证据。

## VIS字段
`visual_id | source_id | source_page_url | image_url_if_stable | title | year/version | platform | mode | menu_path | visible_fields_or_steps | claims | related_mechanism_cards | rights_status | repo_file_if_authorized`

允许按菜单/战术类型批量收集大量**引用记录**，或逐批保存用户/获许可的截图；不要求每轮都写图，也不要因为缺图阻断有可信文字依据的攻略。
