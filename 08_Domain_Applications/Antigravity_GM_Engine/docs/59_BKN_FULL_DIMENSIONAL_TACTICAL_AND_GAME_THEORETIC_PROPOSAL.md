## 3. 终极赢球哲学与自主裁决决策 (Championship Formula & Model Autonomous Judgment)

> **核心叩问**：*布鲁克林篮网如何赢得最后的总冠军？(How does this team win the ultimate victory?)*

拥有凯文·杜兰特与凯里·欧文的球队，在进攻端拥有篮球历史上最不可思议的单挑硬解能力。推演其总冠军夺冠路线，篮网必须克服单打停滞与防守脆弱的顽疾，建立“双核引力反哺射手 + 西蒙斯功能解耦 + 全员无限换防”的必胜公式：

1. **明确进攻双核层级，杜兰特为绝对第一终结点**：
   * 杜兰特触球调定为 `88`，战术槽位锁定 `[Isolation (1), Screen 3PT (14), P&R Ball Handler (4), Post Up High (9)]`。KD 在罚球线以上拥有 97 中投和干拔绝杀权；将 `dish_to_open_man` 提至 `75`，遭遇包夹时必须第一时间转移弱侧底角。
   * 凯里·欧文定为首发第二持球核心（触球 `82`），激活推进特权。拥有顶尖面框单挑（PlayType 1）、高位挡拆持球（PlayType 4）与接球拔干三分（PlayType 14）特权。
2. **本·西蒙斯从“假持球核心”彻底转型为“顶级润滑油与发牌中枢”**：
   * 将西蒙斯触球从 96 **断崖式削减至 50**！战术槽位彻底剔除单打 (1)，绑定 `[Handoff Passer (13), P&R Roll Man (7), Cutter (11), P&R Ball Handler (4)]`。
   * 出球意愿拉满至 `90`！西蒙斯在反击中作为全场推进箭头，半场阵地中落高位充当手递手墙（BrickWall），为赛斯·库里和欧文做掩护发牌，或利用 6'10" 身高空切下顺吃饼。
3. **赛斯·库里与乔·哈里斯“双鬼拍门”空间压制**：
   * 赛斯·库里拥有 91 顶尖三分，首发出任分卫（触球 `54`），主打 `[Screen 3PT (14), Handoff Receiver (12)]`；替补席配备乔·哈里斯（93 三分，触球 `64`）与米尔斯（81 三分，触球 `64`），保证场上时刻维持 3 个以上的顶级射程点。

### 3.2 防守端终极法则：祭出全联盟最残暴的“1到5号位无差别无限换防”
