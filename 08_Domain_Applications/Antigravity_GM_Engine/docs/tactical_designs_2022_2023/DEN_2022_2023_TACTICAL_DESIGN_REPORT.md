## 1. 球队风格诊断与建队思路

### 1.1 现役核心轮换盘点（基于最新 `M02_DEC` 采集）
* **绝对进攻轴心 / 历史级组织中锋**：**尼古拉·约基奇**（C，31.3 MPG，19.7 PPG，12.0 RPG，7.9 APG，中投 `96` / 近投 `93` / 勾手 `94` / 控球 `77` / 后板 `87` / 抢断 `72` / 三分 `78`）。作为两届常规赛 MVP，约基奇是联盟历史顶级的战术发牌大脑。其在罚球线肘区的高位策应、高低位手递手（DHO）、低位背身吸引包夹出球（Dish 98）以及高球商一传推快攻，是掘金战术体系的绝对发动机。
* **后场持球大核 / 冷血单打绝杀手**：**贾马尔·穆雷**（PG，34.6 MPG，20.8 PPG，2.8 RPG，6.1 APG，三分 `86` / 中投 `83` / 突破上篮 `89` / 控球 `89` / 速度 `84` / 抢断 `71`）。顶级挡拆持球人，与约基奇的“1-5号位二人转”是联盟最难防守的攻防博弈死结；具备无球借掩护干拔三分与最后时刻关键单挑硬解特权。
* **历史级高炮台射手 / 进攻空间重锤**：**迈克尔·波特 (MPJ)**（SF，35.3 MPG，23.3 PPG，8.6 RPG，2.6 APG，三分 `93` / 中投 `87` / 突破上篮 `94` / 扣篮 `80` / 速度 `83` / 后板 `71`）。拥有 6'10" 锋线身材与历史级射术，全队得分王。主要任务是通过无球掩护（下掩护、Flare、Floppy、弱侧锤子）完成接球即投（Catch & Shoot），为约基奇内线策应拉扯出极致的半场空间。
* **幽灵空切扣将 / 禁区轰炸机与防守大闸**：**阿隆·戈登**（PF，28.5 MPG，10.7 PPG，5.8 RPG，3.8 APG，突破扣篮 `94` / 原地扣篮 `94` / 突破上篮 `85` / 外防 `80` / 内防 `78` / 速度 `78`）。彻底剥离其持球单打幻想，专注沿底线埋伏（Dunker Spot）的幽灵切入与空接暴扣（Lob City Finisher 金、Rise Up 金）；防守端作为全队单防箭头，对位敌方锋线王牌并负责弱侧沉退协防。
* **极品 3D 冠军后卫**：**肯塔维奥斯·考德威尔-波普 (KCP)**（SG，21.6 MPG，7.1 PPG，三分 `81` / 外防 `78` / 速度 `83` / 抢断 `66`）。外线领防第一工兵，战术端主打无球反跑、定点底角三分与手递手二次突破。
* **第二阵容持球引擎与多面突击手**：**布鲁斯·布朗**（SG，20.1 MPG，3.9 PPG，4.4 RPG，3.1 APG，突破上篮 `83` / 扣篮 `73` / 控球 `74` / 速度 `77` / 外防 `71` / 抢断 `71`）、**雷吉·杰克逊**（PG，19.8 MPG，8.4 PPG，3.6 APG，三分 `81` / 中投 `77` / 控球 `79` / 速度 `79`）。二阵双后卫驱动，雷吉主打挡拆急停中投，布朗主打空切突击与撕咬领防。
* **替补内线群**：**托马斯·布莱恩特**（C，24.6 MPG，10.8 PPG，7.1 RPG，三分 `79` / 上篮 `90` / 原扣 `75` / 勾手 `77`，空间型挡拆外弹中锋）、**德安德烈·乔丹**（C，16.4 MPG，5.7 PPG，5.8 RPG，上篮 `85` / 扣篮 `79` / 盖帽 `79` / 后板 `80`，传统吃饼护筐中锋）、**齐克·纳吉**（PF，10.8 MPG，三分 `83` / 中投 `80` / 原扣 `81`，空间大前锋）。

### 1.2 建队思路定调
* **主建队路线**：**【体系/团队流（组织中锋高位发牌与手递手）+ 双核错位联动 + 四外一内幽灵空切与高位炮台】**。以约基奇为绝对策源中枢，穆雷为外线持球突击手，戈登埋伏底线幽灵空切，波特与 KCP 在外围架设两门无球加农炮，打出全联盟真实命中率最高的团队进攻。
* **教练体系建议**：
  - **ActiveSystem / PreferredSystem**：`2 (Pace & Space)`（四外一内空间跑轰体系）配合 `7 (Seven Seconds)`（丹佛高原主场利用约基奇长传一传打闪电战转换）。
  - **Freelance 1–4 优先级**：
    1. `5 (FOUR_OUT)` / `28 (UNIVERSAL)`（四外一内拉开空间，为约基奇肘区/低位清空中路走廊）
    2. `18 (FLOW)` / `16 (WARRIORS)`（无球连续跑动、手递手掩护与弱侧空切）
    3. `13 (PHILLY_ELBOW)` / `21 (PACE)`（约基奇肘区指挥官专属站位与 21 Delay 推进）
    4. `24 (SEVEN_SECONDS)`（防守反击与早期进攻）
  - **进攻重点 POE 1–3**：
    `3 (Post Up Offense / 内线约基奇策应与强吃)` → `8 (Play Through Star / 围绕约基奇与穆雷)` → `12 (Shoot At Will / Space The Floor 拉开空间投三分)`。
  - **教练节奏与战术倾向**：保持高 `Tempo`（203），战术执行频率 `RunPlayTendency` 设定为 `75`（严格执行半场战术跑位，杜绝盲目单打乱丢）。

## 3. 第二批筛选：轮换阵容时段与攻防优势面

### 3.1 四套核心 5 人阵容时段拆解与进攻联动

1. **阵容 A：首发主力决胜阵**（`穆雷 + KCP + 波特 + 戈登 + 约基奇`，同场约 18–20 分钟）
   * **最大进攻优势面**：**【空间极大化 + 历史级中枢发牌 + 幽灵空切与高空轰炸】**。场上 4 人三分在 78–93 之间，戈登拥有 94 的扣篮与运动能力。对方中锋无法兼顾约基奇的高位策应与底线戈登的偷鸡暴扣，一旦包夹约基奇，波特与 KCP 的致命三分惩罚即刻降临。
   * **筛选联动战术**：`GIVE 53 FIST JOKER`、`GIVE 5OUT NUG 52`、`HIGH 5OUT`、`FIST 15 POP`、`CUT 14 ALLEY`、`QUICK 12 HAMMER`、`FIST 14 STS DOWN`。
2. **阵容 B：衔接段一（约基奇带二阵：约基奇 + 雷吉 + 布朗 + 纳吉 + 波特/KCP）**
   * **最大进攻优势面**：**【约基奇高位发牌辐射二阵空切手与空间射手】**。雷吉打二号控球点，布鲁斯·布朗作为主力空切撕裂手，纳吉与波特在弱侧定点。约基奇作为场上绝对单核，通过手递手与高位策应完全掌控节奏。
   * **筛选联动战术**：`HIGH 15 SPREAD`、`GIVE 52 5OUT`、`GIVE 15 ELBOW FLEX`、`CUT 15 RETURN ALLEY`、`QUICK 13 FLARE`、`PUNCH 14 SLIP`。
3. **阵容 C：衔接段二（穆雷带纯替补阵：穆雷 + 布朗 + 坎帕佐/KCP + 戈登/纳吉 + 布莱恩特/小乔丹）**
   * **最大进攻优势面**：**【穆雷挡拆持球硬解 + 托马斯·布莱恩特外弹空间 + 小乔丹/戈登顺下空接】**。在约基奇下场休息的 8–10 分钟内，球队转为以穆雷为核心的“四外一内挡拆体系”，利用布莱恩特的外弹三分拉开空间，由穆雷完成挡拆突破分球或中距离干拔。
   * **筛选联动战术**：`FIST 15`、`FIST 4 OUT SHORT`、`FIST 15 DOWN SPREAD`、`GIVE 51 5OUT`、`GIVE 35 ELBOW PITCH`、`GIVE 12 FLIP`。
4. **阵容 D：决胜关键时刻收官阵 (Closing Lineup)**（`穆雷 + KCP + 波特 + 戈登 + 约基奇`）
   * **最大进攻优势面**：**【抗包夹、抗无限换防、顶级关键球解构】**。全队具备高战术纪律与球商，利用穆雷与约基奇的高位假挡拆或约基奇 Pinch Post 发牌，根据防守对位灵活点名。
   * **筛选联动战术**：`ISO 1 FIST END`、`ISO 1 GO END`、`FIST 5 END`、`HIGH 4 PINCH END`、`PUNCH 14 SLIP END`、`PUNCH 32 FIST END`。

### 3.2 阵容时段级防守体系设计（持久化教练 + 球员定位）
* **宏观防守诊断**：
  - **优势**：戈登（外防 `80` / 内防 `78`，顶级单防大闸）、KCP（外防 `78` / 抢断 `66`，顶级外线领防撕咬）、布鲁斯·布朗（外防 `71` / 抢断 `71`，强硬换防对位）、约基奇（后板 `87` / 抢断 `72`，极强传球路线预判与防守篮板控制）。
  - **短板**：约基奇缺乏垂直弹跳与横向滑步爆发力（Block `57` / LatQ 较低），若采取深沉退（Drop Coverage）容易被对方顶级后卫（如布克、库里、保罗）借掩护中投军训；小波特横移防挡拆易受掩护挂住。
* **推荐持久化防守设置（马龙教练夺冠防守蓝图）**：
  - **教练防守 POE 1–3**：
    1. `13 (Protect The Paint / 保护禁区)`：收缩内线，封死油漆区直接攻筐。
    2. `18 (Play Physical / 强硬身体对抗)`：外线掩护全力抢过，对抗延误持球人。
    3. `19 (Crash Defensive Boards / 保护防守篮板)`：全员卡位保后板，由约基奇收板立刻发动“四分卫式”前场长传反击。
  - **`HelpDefense`（协防强度）**：设定为 **`50–55`**（适度协防。绝不盲目扑防过度导致漏掉底角三分，发挥戈登与波特的身高协防面积）。
  - **`ZoneUsage`（联防频率）**：保持在 **`5–10`**（常规严格实行人盯人，仅在二阵保护托马斯·布莱恩特防挡拆吃力时短暂使用二三联防）。
  - **核心球员防守战术行为微调**：
    - **约基奇防挡拆**：**坚决实行“平视延误 / 适度上前干扰” (Soft Hedge / At-The-Level)**，约基奇上提到掩护人身前一步干扰后卫干拔与传球，绝不深沉退！
    - **弱侧前锋（阿隆·戈登 / 杰夫·格林）**：执行极度激进的 **`Tag on Roll`（弱侧下沉补位顺下中锋）**，在约基奇延误回位前卡死顺下路线，外线后卫（穆雷/KCP）积极抢过掩护（`GO_OVER`）。
    - **单防箭头**：**KCP** 领防敌方持球主控，**戈登** 锁死敌方侧翼第一王牌得分手。
