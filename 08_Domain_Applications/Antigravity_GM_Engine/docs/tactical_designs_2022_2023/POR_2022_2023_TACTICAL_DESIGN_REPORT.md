# 波特兰开拓者 (POR) 2022-23 赛季攻防战术体系与手册设计报告（Phase 1 方案）

> **依据规范**: `SOP-ANNUAL-TEAM-TACTICAL-DESIGN-V1`  
> **数据基准**: `2022-2023_M02_DEC`（2026-11-26 最新全量采集快照）  
> **当前手册与战术状态诊断**:  
> 1. **双枪后场外线投射爆发力极强但战术缺乏连动**：开拓者拥有全联盟最具威慑力的双火炮后场组合——**达米安·利拉德（34.0 MPG，3PT `92` / 中投 `86` / 控球 `89` / 速度 `88`）+ 安芬尼·西蒙斯（26.1 MPG，3PT `90` / 中投 `81` / 控球 `84` / 扣篮 `89`）**。然而原 `Blazers Playbook (ID=27)` 严重依赖单人单打与简单挡拆，缺乏双枪同时在场时的连环掩护（`STS`）、手递手接力（`GIVE`）与外弹三分联动，导致球权停滞与防守针对；
> 2. **高位双塔策应与手递手发牌价值未被释放**：阵中主力中锋**优素福·努尔基奇（27.2 MPG，11.0 板 4.9 助 / 勾手 `81` / 内防 `80`）**与**萨姆·鲍维（27.1 MPG，8.2 板 4.7 助 / 盖帽 `88` / 内防 `84`）**均具备极高球商与场均近 5 次助攻的高位发牌能力。原战术库却缺少以大个子为轴心的流动手递手（`DHO / GIVE`）与高低位连线，白白浪费了巨型掩护质量与禁区传球视野；
> 3. **极速运动天赋空切与反击利用率低**：球队锋卫线集结了**杰罗姆·柯西（速度 `85` / 扣篮 `88` / 抢断 `80`）**、**多诺万·格林（速度 `98` / 扣篮 `85`）**、**基恩·约翰逊（速度 `99` / 扣篮 `90`）**以及**马蒂斯·塞布尔（外防 `93` / 抢断 `98` / 盖帽 `80`）**等顶级运动怪兽与外线防守大闸，战术库中空切（`Cat 9 Cut`）与早攻战术比重不足，未能将反击抢断转化为高效篮下暴扣；
> 4. **射手 PlayType 亟需规范统一**：全队外线射手必须全部统一校准为真实三分代码 **`14 (3 PT)`**（严禁误填游戏 UI 显示为空的 `15`），彻底释放双枪与空间侧翼的三分轰炸威力。

### 1.2 建队思路定调
* **主建队路线**：**【超级后场双枪挡拆轰炸 + 高位双轴手递手发牌 + 极速反击空切暴扣流】**  
  以达米安·利拉德与安芬尼·西蒙斯超强双枪持球/无球三分牵制为战术第一支点；以努尔基奇与鲍维的巨型掩护和场均近 5 助的高位手递手（`DHO / GIVE`）为轴心枢纽；侧翼柯西、格兰特、多诺万·格林、基恩·约翰逊全面利用速度（85~99）与弹跳（扣篮 84~90）进行大量的反跑空切（`Backdoor Cut / Alley-Oop`）与闪电反击，将外线三分雨与禁区高空轰炸完美融合。
* **教练体系建议**：
  - **PreferredSystem / ActiveSystem**：`7 (Seven Seconds 七秒快攻)` / `2 (Pace & Space 空间跑轰)`（兼顾提速快攻与五外射程拉开）
  - **Freelance 1–4 优先级**：
    1. `5 (FOUR_OUT)`（四外一内，为利拉德与西蒙斯清出最大中路突破与挡拆空间）
    2. `18 (FLOW)`（流动传切体系，利拉德无球穿梭与高位双塔手递手连环发牌）
    3. `24 (SEVEN_SECONDS)`（七秒提速早攻，充分释放柯西与基恩·约翰逊 98+ 极速冲击）
    4. `13 (PHILLY_ELBOW)`（肘区双塔轴心发牌，最大化努尔基奇与鲍维的策应助攻能力）
  - **进攻重点 POE 1–3**：`4 (Pick & Roll Offense 挡拆进攻)` → `8 (Play Through Star 围绕核心打 - Dame Time)` → `12 (Shoot At Will / Space The Floor 拉开空间投三分)`（保持高节奏 `Tempo` 75 与高战术执行度 `RunPlayTendency` 76）。
