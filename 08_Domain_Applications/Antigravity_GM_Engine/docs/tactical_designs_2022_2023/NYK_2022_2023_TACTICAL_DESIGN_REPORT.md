  - **PreferredSystem / ActiveSystem**：保持原版主教练汤姆·锡伯杜的经典标志 **`7 (DEFENSE / 铁血防守)`**，立足于阵地硬碰硬肉搏与保护禁区。

    4. `21 (PACE)`：阵地战拉开错位单挑点名。
