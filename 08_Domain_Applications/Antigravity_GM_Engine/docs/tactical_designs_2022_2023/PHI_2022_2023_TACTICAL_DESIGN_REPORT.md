# 费城76人队 (PHI) 2022-23 赛季攻防战术体系与手册设计报告（Phase 1）

> **依据规范**: `SOP-ANNUAL-TEAM-TACTICAL-DESIGN-V1`  
> **数据基准**: `2022-2023_M02_DEC`（2026-11-26 最新全量采集快照，Team ID = 0, City = Philadelphia, Name = 76ers）  
> **当前手册与配置诊断**: 原版76人战术体系与底层配置存在四大核心痛点——  
> ① **“双核乃至三核”历史级进攻引力未被体系化释放**：2021-22 得分王乔尔·恩比德（中投 `94` / 低位钩手 `90` / 上篮 `92`）拥有历史级内线低位与高位面框统治力，詹姆斯·哈登（传球视野 `92` / 控球 `92` / 突破 `90`）为当代顶尖挡拆发牌大师，加之查尔斯·巴克利（前场后板 `95` / 扣篮 `88` / 助攻 `4.9`）的野兽级前锋冲击力。原版手册中缺乏高低位内外立体联动的现代战术，过多依赖机械单打；  
> ② **挡拆外弹三分与短顺下发牌战术严重匮乏**：原手册缺乏针对防守沉退的 `FIST 15 POP` 外弹三分，以及防夹击短顺下 4打3 突分底角射手（`FIST 5 SHORT 4 CNR`），导致面对季后赛高压换防或延误夹击时进攻容易停滞；  
> ③ **替补席火力衔接脱节**：第二阵容拥有高爆发能量内线蒙特雷兹·哈雷尔（上篮 `90` / 扣篮 `85`）与极速后卫格兰特·里勒（速度 `96` / 控球 `89` / 三分 `84`）、中投微波炉谢克·米尔顿（中投 `89`），但原版替补槽位仅填寥寥数条战术，二阵常陷入各自为战；  
> ④ **球员 PlayType 与 Initiator 错配**：原档中哈登与马克西的发起人标志位存在缺失，且全队多名射手（马克西、哈里斯、科克马兹、麦克丹尼尔斯、尼昂）存在三分战术类型缺失或误填 `15`（2K22 中 `14` 才是有效三分枚举，`15` 为无效空值）。

### 1.2 建队思路定调
* **主建队路线**：**【内线低位统治 + 挡拆双核联动 + 强力锋线错位压迫流】**。
  - 以乔尔·恩比德为全队第一进攻支点与禁区引力源泉，低位单打与高位面框迫使对手收缩防线或包夹；
  - 詹姆斯·哈登与恩比德组成联盟最致命的高位挡拆（P&R）/外弹（Pick & Pop）二人组，配合马克西的极速弱侧突击；
  - 查尔斯·巴克利与托比亚斯·哈里斯提供锋线高低位碾压与错位点名，外围配置马克西（`88` 三分）、哈登（`81` 三分）、哈里斯（`80` 三分）、尼昂（`84` 三分）、科克马兹（`78` 三分）拉开五外空间；
  - 替补阶段由里勒与哈雷尔发动快速挡拆冲击禁区，米尔顿在中距离单挑拔射，维持高强度得分节奏。
* **教练体系建议**：
  - **PreferredSystem / ActiveSystem**：采用 **`1 (Post Centric 低位中心体系)`** 配合 **`4 (Seven Seconds 提速早攻)`**。阵地战主打恩比德与巴克利的低位内线碾压，反击战利用巴克利与马克西的超高推进速度打出闪击战。
  - **Freelance 1–4 优先级**：
    1. `5 (FOUR_OUT)`：四外一内站位，恩比德/巴克利沉底低位，其余 4 人拉开三分线，清空中路走廊；
    2. `13 (PHILLY_ELBOW)`：76人招牌肘区策应跑位，恩比德或巴克利在罚球线发牌，后卫无球剪刀空切；
    3. `28 (TWENTY_ONE_DELAY)`：21 Delay 边线手递手延迟落位，适合哈登与马克西在边线快速发动挡拆；
    4. `18 (FLOW)`：流动传切体系，增加弱侧射手无球下掩护与横向穿插。
  - **进攻重点 POE 1–3**：
    - `3 (Feed The Post / 给低位球)`：战术首要原则是把球喂入禁区，最大化恩比德与巴克利的统治力；
    - `7 (Play Through Star / 围绕核心打)`：阵地战决策权牢牢掌握在恩比德、哈登两大超级巨星手中；
    - `12 (Limit Transition / Space The Floor 拉开空间投三分)`：外线射手坚决站定三分线拉扯空间，投进空位远投并限制对手快攻。

## 3. 第二批筛选：轮换阵容时段与攻防优势面

### 3.1 四套核心 5 人阵容时段拆解与进攻联动

     恩比德与巴克利在低位形成恐怖的前场篮板与禁区杀伤力，防守人根本无法同时协防两人；外围哈登负责挡拆与全局掌控，马克西提供第一步突破与致命接球远投，哈里斯在弱侧提供高炮手中距离与底角三分支援。

   - **最大进攻协同优势面**：**超强大核牵制 + 高能量替补内线顺下 + 极速反击突刺**。
     当恩比德或哈登单核在场时，哈雷尔提供高强度的挡拆顺下与前场板拼抢，里勒与米尔顿提供第二持球点的速度冲击与中距离硬解，麦克丹尼尔斯与豪斯沿底线切入或底角埋伏。
