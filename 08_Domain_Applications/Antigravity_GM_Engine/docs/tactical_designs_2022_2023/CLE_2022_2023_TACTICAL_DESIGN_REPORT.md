> **依据规范**: `SOP-ANNUAL-TEAM-TACTICAL-DESIGN-V1`

### 1.2 建队思路定调
* **主建队路线**：**【后场双星驱动 + 双塔高低位空接护筐 + 侧翼空切与外线惩罚流】**。
  - 以米切尔与加兰作为第一发起点，利用 97 速度与 90/87 三分引力发起高位挡拆；
  - 莫布利与阿伦同时在场时主打 **牛角落位 (Horns)** 与 **高低位配合 (High-Low)**：阿伦强侧下沉提供极致吃饼扣篮威慑，莫布利在罚球线/肘区负责短顺下 4 打 3 发牌或空切；
  - 奥科罗、勒韦尔、丹尼·格林埋伏弱侧或反跑空切，彻底激活半场立体进攻层次。
* **教练体系建议**：
  - **PreferredSystem / ActiveSystem**：保持原版极度契合的 **`7 (Defense First 防守为主/防守优先)`**（深度匹配骑士 2022-23 赛季全联盟第 1 的防守效率与失分全联盟最低的硬朗气质）。
  - **Freelance 1–4 优先级**：
    1. `28 (CELTICS / 3_OUT_2_IN)` 或 `5 (FOUR_OUT)`：双塔同时在场时提供清晰的高低位站位，莫布利高位拉扯，阿伦低位沉底；
    2. `18 (FLOW)`：无球端双星与射手在双塔连续掩护下的无球流动与掩护跑动；
    3. `13 (PHILLY_ELBOW)`：莫布利在肘区持球发牌，全队弱侧跑电梯门与反跑后门；
    4. `24 (SEVEN_SECONDS)`：双塔收下篮板后由米切尔与加兰极速推进反击早攻。
  - **进攻重点 POE 1–3**：
    - `4 (Pick & Roll Offense 挡拆进攻)`：加兰/米切尔与阿伦/莫布利的教科书级高位挡拆；
    - `7 (Get To The Basket 杀入禁区/冲击篮下)`：米切尔（93扣篮）与阿伦/莫布利的高空作业空中轰炸；
    - `8 (Play Through Star 围绕核心打)`：保证米切尔、加兰、莫布利在阵地战中拥有最高优先级的终结与分配球权。

### 3.2 阵容时段级防守体系设计（持久化教练 + 球员定位）

* **宏观防守诊断**：
  - **优势**：**全联盟首屈一指的禁区禁飞区与弱侧扫荡体系**。莫布利（内防 `88` / 外防 `80` / 盖帽 `90`）具备防守一阵级别的换防弹性与弱侧大帽能力；阿伦（内防 `82` / 盖帽 `80` / 防守篮板 `87`）是坚不可摧的篮下磐石；外线奥科罗（外防 `82` / 速度 `81`）是撕咬对方王牌的第一道铁闸。
  - **短板**：加兰（内防 `30` / 外防 `74`）与米切尔（内防 `61` / 外防 `73`）体型较小，面对重型持球后卫或锋线强吃时存在防守短板。
* **推荐持久化防守设置**：
  - **教练防守重点 POE 1–3**：
    - `13 (Protect The Paint / 护筐)`：依托双塔禁区天然高度封死油漆区；
    - `18 (No Threes / 限制外线三分)`：奥科罗领防贴身，其余外线防守人坚决绕过掩护贴防；
