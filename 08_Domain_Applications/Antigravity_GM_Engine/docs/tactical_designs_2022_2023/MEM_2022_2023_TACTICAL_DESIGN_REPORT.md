### 1.2 建队思路定调
* **主建队路线**：**【超级持球大核攻筐突破 + 立体空接顺下轰炸 + 内外两开双核联动流】**。
  - 以莫兰特 99 极限速度与挡拆下顺为绝对轴心引擎，亚当斯作为第一掩护墙；
  - 小贾伦·杰克逊（JJJ）与克拉克提供极致的纵向立体空接威胁与横向外弹三分牵制（JJJ 80 3PT）；
  - 贝恩与肯纳德在弱侧与底角构建致命三分炮火网，彻底惩罚一切收缩禁区的防守人；
  - 替补阶段由泰厄斯·琼斯梳理半场阵地，奥克利提供 96 中投的硬解无差别单吃，保持全场 48 分钟高压进攻。
* **教练体系建议**：
  - **PreferredSystem / ActiveSystem**：保持并融合 **`7 (Defense First / 防守立足反击)`** 与 **`2 (Pace & Space / 空间跑轰提速)`**，既继承灰熊“铁血防守反击”的基因，又全面释放莫兰特反击推进与全队三分空间。
  - **Freelance 1–4 优先级**：
    1. `21 (PACE)` 或 `5 (FOUR_OUT)`（五外/四外一内，为莫兰特彻底清空禁区单挑突击与空接通道）；
    2. `18 (FLOW)` / `16 (WARRIORS)`（弱侧贝恩+肯纳德无球交叉掩护、电梯门与连续跑动）；
    3. `3 (GRIZZLIES_PUNCH)` 或 `13 (PHILLY_ELBOW)`（高位发牌、亚当斯手递手与 JJJ 错位进攻落位）；
    4. `24 (SEVEN_SECONDS)`（抢下防守篮板后迅速由莫兰特提速打转换快攻）。
  - **进攻重点 POE 1–3**：
    - `POEOffense`: `1 (Get to Basket / 冲击篮筐)`（莫兰特、克拉克坚决攻击篮下，制造杀伤与空接）；
    - `POEOffense2`: `9 (Shoot at Will / 快速果断出手)`（莫兰特突分后外线射手坚决投射三分，不犹豫拖沓）；
    - `POEOffense3`: `10 (Crash Offensive Boards / 冲抢进攻篮板)` 或 `12 (Limit Transition / 控制退防)`（依托亚当斯前板统治力制造二次进攻机会）。
