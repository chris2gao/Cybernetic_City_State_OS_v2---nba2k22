# 亚特兰大老鹰 (ATL) 2022-23 赛季攻防战术体系与手册设计报告（Phase 1 方案）

> **依据规范**: `SOP-ANNUAL-TEAM-TACTICAL-DESIGN-V1`  
> **数据基准**: `2022-2023_M02_DEC`（2026-11-26 最新全量采集快照）  
> **当前手册与战术状态诊断**:  
> 1. **双全明星控卫引擎驱动但缺乏战术联动**：在引进**德章泰·穆雷（29.8 MPG，14.6分 6.5板 7.4助，外防 89 / 抢断 84）**后，老鹰与**特雷·杨（35.2 MPG，18.3分 9.7助，控球 96 / 中投 90 / 3PT 82）**组建了全联盟极具威胁的持球双核后场。然而原版手册偏重传统的单持球高位挡拆，严重缺乏双核同场时的强弱侧联动、弱侧手递手（`Handoff / GIVE`）以及无球外弹配合，导致双核容易沦为各自带队单打；
> 2. **空接空袭优势未在现代战术库中最大化发掘**：球队坐拥克林特·卡佩拉（30.0 MPG，14.1板 10.1分，原扣 89 / 站扣 79 / 盖帽 87）、约翰·科林斯（25.5 MPG，10.4分 5.8板，突扣 81 / 原扣 81 / 中投 93 / 3PT 78）以及高能飞人杰伦·约翰逊（突扣 88 / 速度 82）等顶级吃饼集群，但原战术库中缺少现代精准空接切入战术（`Alley-Oop`）与短顺下（`Short Roll`）四打三空切，禁区终结效率存在巨大未开发红利；
> 3. **全队射手群 PlayType 亟需规范统一**：博格丹·波格丹诺维奇（3分 92）、萨迪克·贝（3分 86）、约翰·科林斯（3分 78）、德安德烈·亨特（3分 73）等核心终结者，必须全部统一规范为真实三分代码 **`14 (3 PT)`**（严禁误填游戏 UI 显示为空的无效代码），彻底释放老鹰外围万箭齐发的空间牵制力。

### 1.2 建队思路定调
* **主建队路线**：**【双控卫引擎驱动 + 空接空袭与外围投射错位流】（Dual-Playmaker P&R Lob-City & Perimeter Spacing）**  
  以特雷·杨的历史级超远射程与挡拆发牌为第一动力源，结合德章泰·穆雷的强突与急停中距离；内线由卡佩拉和科林斯构建全联盟最具威慑力的“垂直空间（Vertical Spacing）”空接威胁，迫使对手防守收缩；外线由波格丹诺维奇（3PT 92）、萨迪克·贝（3PT 86）与科林斯（3PT 78）布设高密度的外拆三分火力网。
* **教练体系与战术倾向建议**：
  - **PreferredSystem / ActiveSystem**：`2 (Pace & Space / 五外跑轰空间)`（原档 PreferredSystem 为 1，统一优化为 2，最大化外线拉开与内线空接走廊）
  - **Freelance 1–4 优先级**：
    1. `21 (PACE)`（提速早攻与快速跨场转移球，发挥特雷·杨与穆雷的推节奏优势）
    2. `28 (PACE & SPACE)`（四外一内/五外拉开，为卡佩拉与科林斯清空中路顺下垂直空接通道）
    3. `18 (FLOW)`（波格丹诺维奇与萨迪克·贝弱侧高频无球交叉掩护，彻底拉扯对手防线）
    4. `5 (FOUR_OUT / 4 OUT 1 IN)`（经典四外一内站位，卡佩拉低位下沉或中路高位挡拆）
  - **进攻重点 POE 1–3**：
    - POE 1: `4 (Pick & Roll Offense / 挡拆进攻)`（杨/穆雷弧顶主导多重挡拆阅读）
    - POE 2: `9 (Get To The Basket / 冲击篮下与空接)`（卡佩拉/科林斯/杰伦·约翰逊暴力空切终结）
    - POE 3: `12 (Shoot At Will / Space The Floor / 拉开空间投三分)`（波格丹、萨迪克·贝、科林斯坚决外弹出手三分）
  - **比赛节奏与战术纪律**：
    - `Tempo`: 保持在 **`188`（高速跑轰，充分释放年轻阵容反击快攻与空接推进潜力）**
    - `RunPlayTendency`: 保持在 **`75–80`**（高战术执行纪律，确保挡拆跑位与无球掩护到位率）
