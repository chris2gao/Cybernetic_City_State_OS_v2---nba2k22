### 1.2 建队思路定调
* **主建队路线**：**【现代双持球超巨驱动 + 五外极致空间错位流】（Dual-Heliocentric P&R & 5-Out Spacing）**  
  以东契奇与欧文这对历史级单挑与挡拆发动机为核心，场上常态配置 3–4 名三分射程在 `79–88` 的空间点（伍德、佩金斯、小哈达威、布洛克、贝尔坦斯），彻底拉空油漆区。无论对手采取沉退（Drop）、夹击（Trap）还是无限换防（Switch），独行侠均拥有直接打穿防线的武器库：东契奇重型低位点名小个、欧文极速跳投单挑大个、伍德外弹三分惩罚中锋蹲坑。
* **教练体系与战术倾向建议**：
  - **PreferredSystem / ActiveSystem**：`2 (Pace & Space / 五外跑轰空间)`（原档 PreferredSystem 为 0，统一为 2，契合五外拉开哲学）
  - **Freelance 1–4 优先级**：
    1. `28 (PACE & SPACE)` / `5 (5-OUT MOTION)`（主打全场五外拉开，彻底为东契奇和欧文清空弧顶与突破走廊）
    2. `21 (PACE)`（提速早攻与快速转移球）
    3. `18 (FLOW)`（弱侧射手连续无球交叉掩护，释放小哈达威、贝尔坦斯无球牵制）
    4. `13 (PHILLY_ELBOW)` / `0 (SPREAD)`（高位与肘区双塔策应手递手）
  - **进攻重点 POE 1–3**：
    - POE 1: `4 (Pick & Roll Offense / 挡拆进攻)`（东契奇/欧文作为核心发动）
    - POE 2: `8 (Play Through Star / 围绕球星打)`（双星主导进攻回合）
    - POE 3: `12 (Shoot At Will / Space The Floor / 拉开空间投三分)`（射手群果断出手外弹与定点三分）
  - **比赛节奏与战术纪律**：
    - `Tempo`: 保持在 **`40–44`**（全联盟最慢节奏之一，契合基德与东契奇极具耐心的阵地战拆解与错位猎杀）
    - `RunPlayTendency`: 保持在 **`85`**（极高的战术执行率，确保挡拆与掩护到位率）

## 3. 第二批筛选：轮换阵容时段与攻防优势面

### 3.1 四套核心 5 人阵容时段拆解与进攻联动

1. **阵容 A：首发主力双核五外阵**（`欧文 + 东契奇 + 沃伦/布洛克 + 佩金斯 + 伍德`）
   - **最大进攻优势面**：**历史级双核驱动 + 全员 5-Out 极致空间 + 挡拆内外双威胁**。东契奇与欧文同场，一人控球发起，另一人埋伏弱侧或借掩护二次突袭；内线伍德与佩金斯兼具外弹与切入，让对手防守体系无论采取何种策略均面临破绽。
   - **筛选联动战术**：`FIST 5OUT 4`、`FIST 14 STS DOWN`、`FIST 51 5OUT STS`、`FIST 14 SIDE STS`、`GIVE 51 5OUT`、`CUT 15 RETURN ALLEY`。
2. **阵容 B：衔阶段欧文带替补 / 东契奇带替补**（`欧文/东契奇 + 小哈达威 + 布洛克 + 贝尔坦斯 + 伍德/佩金斯`）
   - **最大进攻优势面**：**一核支配 + 四射手重炮轰炸**。当东契奇下场休息时，欧文掌控全局，利用贝尔坦斯、小哈达威、布洛克的高频无球跑动，撕裂对手替补防线；挡拆外拆与底角定点三分极为凶悍。
   - **筛选联动战术**：`FIST 25 5OUT DOWN`、`FIST 4 OUT SHORT`、`QUICK 12 HAMMER`、`GIVE 42 HORNS FIST`、`PUNCH 3 HAMMER`。
3. **阵容 C：纯替补乱战阵**（`特里 + 小哈达威/斯特林·布朗 + 约什·格林 + 贝尔坦斯 + 莫塞斯·布朗`）
   - **最大进攻优势面**：**速度推反击 + 简明内线吃饼 + 底角外弹三分**。缺少超巨单挑，主打高容错的简洁战术：特里与莫塞斯打直接高位顺下吃饼，格林空切，贝尔坦斯在弱侧牵制。
   - **筛选联动战术**：`FIST 15`、`FIST 5OUT 10`、`FIST 14 POP`、`CUT 2 DIVE 4 OUT`、`CUT 14 ALLEY`、`QUICK 13 CURL`。
4. **阵容 D：决胜关键时刻 Closing Lineup**（`欧文 + 东契奇 + 小哈达威/布洛克 + 贝尔坦斯/佩金斯 + 伍德`）
   - **最大进攻优势面**：**极致防换防单挑 + 双星冷血绝杀 + 空间极致拉开**。对手关键时刻必然采取无限换防，常规战术失效，依赖东契奇的点名低位背打、欧文的极速干拔跳投以及外弹三分绝杀。
   - **筛选联动战术**：`ISO 1 FIST END`、`ISO 1 GO END`、`FIST 5 END`、`PUNCH 32 FIST END`、`HIGH 4 PINCH END`、`QUICK 12 END`。

### 3.2 阵容时段级防守体系设计（持久化教练 + 球员定位）
* **宏观防守诊断**：
  - **优势**：内线拥有**佩金斯**（内防 `77` / 盖帽 `73` / 后板 `81`）、**伍德**（后板 `88` / 盖帽 `71`）与替补**莫塞斯·布朗**（盖帽 `75` / 后板 `83`），具备合格的篮板保护与护筐轮转；外线有**布洛克**（外防 `77`）与**约什·格林**（速度 `87` / 外防 `76`）可承担盯防对方箭头任务。
  - **短板**：后场双核**东契奇**（外防 `71`，横移相对较慢）与**欧文**（外防 `69` / 内防 `31`）在防守端抗强突能力有限，必须通过锋线积极轮转与内线适度协防来弥补。
* **推荐持久化防守设置**：
  - **教练防守 POE 1–3**：
    - POE 1: `13 (Protect The Paint / 保护油漆区)`（利用佩金斯/伍德收缩禁区，封锁攻筐）
    - POE 2: `18 (Limit Perimeter Shots / 限制外线三分)`（底角寸步不离，布洛克绕掩护贴死射手）
    - POE 3: `19 (Defensive Rebound / 保护后场篮板)`（东契奇场均 8.9 板，全队保护后场篮板推反击）
  - **协防与联防设置**：
    - `HelpDefense`: 设为 **`50–55`**（保持中高强度内线补位与收缩，但避免过度协防漏空角三分）
    - `ZoneUsage`: 设为 **`5–10`**（以人盯人防守为主，仅在替补内线移动过慢时适度使用联防藏拙）
  - **球员个人防守定位倾斜**：
    - **布洛克 / 约什·格林**：全场领防对方核心后卫/锋线，提升 `ContestShot` 与 `OnBallDefense`；
    - **佩金斯 / 伍德 / 莫塞斯·布朗**：专注于禁区顶防与护筐，提升 `BlockShot` 与防守篮板卡位；
    - **东契奇 / 欧文**：尽量对位对方底角 3D 射手以节省进攻端体能，利用高球商判断抢断传球路线（`PassInterception`）。
