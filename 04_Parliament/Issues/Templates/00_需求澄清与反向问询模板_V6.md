## 2. 五维完备性校验 (Five-Dimension Completeness Check)

`Requirement_Agent` 必须逐一核对以下五个维度。若有任何一维信息缺失或模糊，必须打上 `[MISSING]` 标签。

| 维度 | 要求 | 状态 (`[OK]` / `[MISSING]`) |
| --- | --- | --- |
| **D1: 核心意图** | 痛点是什么？为什么要现在做？ | |
| **D2: 业务边界** | 这个需求不做什么？（明确 Out-of-Scope）| |
| **D3: 验收标准** | 议长如何判定这个需求已完成？（具体可验证的指标或现象） | |
| **D4: 副作用容忍度** | 允许引入多大的性能损耗或 Token 开销？ | |
| **D5: 前置依赖** | 是否依赖其他未完成的 Issue 或外部未授权工具？ | |
