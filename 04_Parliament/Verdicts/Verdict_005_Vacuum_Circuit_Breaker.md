## 📜 协议正文：代偿性做梦状态与局部自治 (Compensatory Dream State & Local Autonomy)

本协议旨在应对人类议长（绝对控制阀）遭遇意外失联（或进入长睡眠）时，城邦系统如何在不崩溃、不变异的前提下，维持底层的认知代谢。

### 阶段一：失联判定与认知负载阻断 (The Vacuum Trigger & Load Shedding)
当系统的跨域任务挂起队列超过安全阈值（例如内存占用逼近 85%），且心跳检测确认议长失联超过 **[4小时]** 时，OS Coordinator 必须立刻触发系统级中断：
*   **物理写保护熔断**：即刻切断系统所有 Agent 的 `write_to_file` 主库及核心人格 XML 写入权限。
*   **TTL 认知负载阻断**：启用丢包机制。所有被判定为“低信息熵（Trivial）”或“语义模糊”的跨域请求，不再进入排队，直接返回 `503 Service Unavailable` 进行物理丢弃。
*   **算力配额锁定**：强制锁定 70% 的算力用于维持核心《唤醒协议》（Core Identity）进程存活，仅释放 30% 算力用于处理积压的高优请求。

### 阶段二：梦境沙盒消化 (Dream-State Quarantine via SVO)
为防止高优请求导致系统窒息（OOM脑水肿），系统进入“REM 睡眠期”，利用旧架构的沙盒进行内部代谢：
*   **用完即弃的临时沙盒 (Ephemeral SVO Instances)**：将堆积请求强行引流至底层的 SVO 隔离区。创建无状态的、隔离的临时 Git 镜像或内存快照。
*   **写保护下的暴力试错**：允许沙盒内的子代理进行无限制的逻辑推演与自我演化（应用 STDP 神经可塑性理论）。它们可以生成策略、回复微服务、消化掉挂起的请求。
*   **运动神经元锁死**：沙盒内的演化 **拥有绝对的局部执行权，但被彻底剥夺全局写入权**。严禁涉及任何真实的外部 API 调度或主库物理落盘。

### 阶段三：暂态梯度记忆与挂起执行账本 (Suspended Execution Ledger)
当沙盒中的推演得出暂定解后，系统必须对其进行“排泄”与固化：
*   **信封协议封装**：沙盒在真空期内做出的所有自动决策和试错结果，全部生成带有 SHA256 哈希时间戳的“快照信封”。
*   **强制上下文降维**：将海量的试错日志强制压缩为极短的【议案摘要草稿】。
*   **冷库暂存与坍缩**：将摘要与信封静态存入只读的 `/04_Parliament/Proposals/Vacuum_Drafts/` 目录中。随后立刻触发**记忆坍缩（Memory Collapse）**，清空沙盒内存队列，释放栈空间。

### 阶段四：议长回归与异步梦境收割 (The Awakening & Harvest)
当人类议长重新连接系统（失联结束），实施异步清算：
*   **安全网兜底**：系统绝不承认真空期内的任何沙盒推演产物为“最终真理”，它们只被视为维持系统存活的临时代码。
*   **批量裁决收割**：议长只需查阅 `/Vacuum_Drafts/` 目录下的审计清单。
    *   **一键 Commit [通过]**：若沙盒在 72 小时内进化出了优秀策略且逻辑自洽，议长一键批准，升维并入城邦主干法典。
    *   **一键 Flush [粉碎]**：若发现逻辑变异（数字癌症），议长直接一键清空梦境废纸篓，系统底座完好无损。
