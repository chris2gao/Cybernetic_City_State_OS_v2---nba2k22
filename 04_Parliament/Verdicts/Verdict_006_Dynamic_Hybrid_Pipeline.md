## 【法庭总则：皮层-丘脑动态混合架构 (Cortical-Thalamic Dynamic Hybrid Architecture)】

面对极端的逻辑死循环与状态过载风险，纯粹的单体架构必将导致 GPU 显存耗尽 (OOM)，纯粹的微服务架构必将引发 RPC 广播风暴。
本庭宣布：废止单纯的形态之争，全面实装**“动态混合门控”**与**“自适应降级熔断”**机制。

### 第一条：动态混合拓扑模式
系统摒弃静态绑定，赋予管线架构以拓扑可塑性：
1. **常态聚合（胼胝体直连）**：在常规知识组装与平级推理中，`Assembly_Agent` 与 `Exam_Agent` 保持在同一单体进程运行，以光速共享内存指针，防止“上下文断裂综合征”。
2. **动态剥离（抑制性边界）**：一旦进入深水区计算（如多重交叉辨别），`Exam_Agent` 被瞬间剥离为独立微服务，建立强物理隔离，防止局部运算错误引发全局幻觉雪崩（避免“认知癫痫”）。

### 第二条：丘脑级安全降级与熔断回退
为彻底抵御恶意算力枯竭，部署“丘脑级网关（Thalamic Gateway）”作为最高级物理断路器：
1. **防网络瘫痪（微服务模式下）**：引入令牌桶算法。一旦判定 `Assembly_Agent` 与 `Exam_Agent` 间发生死循环 RPC 请求，立刻强行切断连接。中止局部推演，抛出异常阻断微服务风暴。
2. **防 GPU OOM（单体模式下）**：部署滑动窗口监控 Token 膨胀斜率。若检测到指数级暴涨并逼近显存红线，立即执行“休克疗法”：强制截断上下文，丢弃暴走的中间过程，强制将系统降级至低功耗安全态。

### 第三条：全局差分状态同步 (Delta-Sync)
解耦状态下的通信，严禁全量上下文序列化。仅传输必需的局部变量，并通过 **Delta-State 差分同步与不可变账本**将验证结果拼接回主线，完美兼顾防幻觉污染与防状态断裂。
