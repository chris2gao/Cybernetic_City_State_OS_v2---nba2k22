# REA calendar automation boundary

## Verified date operation

`rea_read_today.js` is a one-shot REA Frida script. Discover the current NBA2K22 PID and verify the installed executable against the candidate build SHA256 before attaching. Use `instrument_with_frida` with mode `attach`, device `local`, that PID, source_kind `file`, and this script's absolute path. A short observation window is sufficient. Require one `REA_NATIVE_TODAY` message with the bound PID and clean teardown. The output is game civil time. No native getter or simulation is invoked.

The script checks Win64 PE and timestamp, the existing GameMode getter code bytes and vtable binding, then double-reads the date and identity. The file-backed entry was exercised with REA on PID 10216 after the single-day trial: `0x2b7d0000` → 2021-12-29 00:00. Source SHA256 `f7b31fc51291a2ca83fadb6b698b5c3bea6040d2ee6289ff580491259f20bb30`. REA observation `ev_40c2604cbe0a1a2a6c63202cea6af50cfdd434f2516804228da53f2de80c4e9f` reported no cleanup error. This read does not attest the loaded save slot or session epoch. Bind those independently in the caller.

## Simulation entry research

[The 2021-12-28 live receipt](https://github.com/chris2gao/Cybernetic_City_State_OS_v2---nba2k22/issues/37#issuecomment-6702489511) anchors the runtime callsite `0x12690dc` inside dispatcher `0x1268320`. The dispatcher prepares the stack-local context with `0x12613e0`, passes it from `[rbp-0x68]` to `0x11be250`, and invokes cleanup `0x1261260` after return.

The second live correlation, 2021-12-29, resolved the exact command. The original menu branch at `0x7e9f27` creates a stack payload and invokes `0x1268320` at `0x7e9f46`, with ECX **17** and RDX pointing to that payload. REA observed the pointer to module vtable `0x2479e30` at +0, selected SCHEDULEDATE word `0x2b7d0000` at +8, and selector **1** at +16. The dispatcher resolves the typed payload via query key `0x1c91a90b` and computes the next-day native boundary before invoking the simulation wrapper. This is the observed Win64 command boundary, with the payload pointer valid during the original call. The command evidence is in `sim-candidate.json`.

The exact chain is the regular-season menu callback `0x7e9b80` → menu callsite `0x7e9f46` → dispatcher `0x1268320` → wrapper `0x11be250` → internal `0x11be290`. The parent stack includes `0x763ab9`, `0xfd3b8f`, and `0xfedd71`. The menu calls `0x7ac500` afterward. The earlier overlay chain remains a static alternate, outside this observed path.

REA additionally verified the virtual type-query leaf `0x82b8f0` using a 24-byte scratch object with vtable `0x2479e30`, a date word at +8, and selector 1 at +16. It returned the scratch pointer for query key `0x1c91a90b`, rejected the negative key, and left the scratch inputs intact. Evidence `ev_911a8506b20cf5c9c8acee2f67d741b4d216ca77b61e3406970a82b63d43fb2f`. This only verifies the type-query contract. The test did not call the dispatcher or simulate a game.

With December 29 selected, both wrapper entries carried `0x2b7e0000` (2021-12-30 00:00) as the target. In order, the wrapper returned 0 then 1, while the dispatcher returned `0xd72e55d5` then `0x504521a8`. No retry policy is inferred from these two engine entries. After the UI operation, Today was 2021-12-30 00:00, Game IDs 516–524 were all final and natively simulated, the same-unit team/player Box readback conserved both scores in 9/9 games, and the four December 30 games stayed pending. The save disk hash stayed unchanged. This evidence establishes one runtime window on the identified build. Raw pointers and game bytes stay private.

REA independently enumerated the NBA2K22 visible window on the same still-running PID. Its thread was **3836**, whereas both simulation entries and their returns were observed on **3128**. The existing `research/rea_native_control/runtime/gui_once.js` schedules on the visible window's thread. Its selector cannot be used as proof of correct simulation thread affinity.

**External execution remains disabled.** A separately authorized external trial requires an engine-owned submission or verified safe execution point on the observed simulation thread. Use date/readback, exact final set, Box verification and non-replay checks. Encountering a prompt ends the bounded trial pending the user. Handling injuries and draft prompts is outside this calendar mechanism.
