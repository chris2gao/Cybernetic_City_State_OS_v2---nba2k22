# 一次性实机测试准入

当前门为 `LIVE_SIM_AUTHORIZATION_REQUIRED`，直接 Native 调用另因 `SIM_CALL_UNVERIFIED` 禁用。本轮不执行任何步骤。下一次现场动作以**一次 Human 操作原生 Calendar UI，观察对应调用链**为限。直接调用须等 ABI、对象、线程和完成条件核证后另外提案。静态证据锚点及断言见 [Native dossier](native-calendar-dossier.md)。

## 提交给 Human 的候选参数

| 项 | 约束 |
|---|---|
| 存档 | 新建的离线、可丢弃克隆槽，候选标签 `ISSUE37_SIM_PROBE`。从已有可复原的历史起点副本制备，由 Human 指定实际路径和槽，固化世界线、源/目标备份哈希。该标签目前未绑定任何文件。R0 对照槽保留原样。 |
| 日期与期望 | 历史参考 Today **2021-12-21** → 观察停止 **2021-12-28**，历史上 `[2021-12-21, 2021-12-28)` 有 **44 场**。现场先只读锁定候选快照、比赛 ID 和当前赛季事件，取得用户所见 UI 目标日期及终点映射。只有精确复现历史窗口且 44 场集合逐项一致时，此参数组才有效。若不同，返回新的明确起止日期与逐场名单，再由 Human 审核。 |
| Build 与现场 | 固定 PE SHA256 和进程 epoch。离线 MyLEAGUE 常规赛 Calendar，正确克隆槽，空闲、无进行中比赛/保存/阻断对话，范围不跨截止日、全明星、常规赛末或其它重大事件。 |
| 启动方式 | 单次用户原生菜单动作。按现场单独授权捕捉 overlay 分支、线程身份、目标日期转换、寄存器/栈及退出状态，再用现有 Reader 读回。断点、进程附加、代码钩子须按现场工具实际权限另核；禁止用日期写入代替 UI 或原生模拟。 |
| 成功 | 回到预登记空闲日期，全部预登记场次原生 `is_final/was_simulated`、赛程身份完整，队伍与球员 Box 通过同采集单元校验。只到日期、任一缺队/缺分/缺 Box 则保留部分结果。 |
| 停止 | 仅一次触发，最多 120 秒观察预算，发现跨界、崩溃、卡住、模态对话、存档/进程/模式切换、赛果缺失、意外保存或无法判断副作用，停止发动作，保留读回与日志。超时后禁止再次触发。不能把这个预算当作游戏任务被取消的证明。 |
| 恢复 | 现场前核验离线冷备副本哈希，记录源槽只读边界。出现未知副作用时隔离克隆槽并保留现场证据，等待 Human 另行决定恢复；恢复若获批，应在游戏关闭且无写句柄后将已验证副本恢复到新的隔离槽，复核目标和源哈希，历史库按原样保留。 |

上述日期、数量有历史来源。**实际克隆槽、场次清单、当次日期和 UI 终点仍须在授权前绑定**，不能用历史值冒充现场观测。若需要更短窗口，从新只读快照选择第一个无事件且有赛程的单日窗口，给出具体日期、比赛 ID 与数量之后再申请同样的单次操作。此次不批准或执行任何恢复、Setter 或无人值守赛季动作。
