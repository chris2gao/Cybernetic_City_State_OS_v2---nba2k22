# W03-09 Codex Review Guide

## 1. 重点审核内容
1. **选秀保护条款的结算**:
   - 选秀权在交易时附带的保护条款（如前 5 保护）由位段维护。在乐透抽签结束后，若该签落在保护区间内，所有权不会发生转移，而是在后续年份按顺延规则结算。
2. **选秀顺位状态时钟**:
   - `0xec9610` 会推进选秀顺位时钟（`[rax + 0xc0]` 递增）。只有在处于选秀大会阶段（Draft Day）时，调用该函数才具备完整的 UI 与数据呈现。
3. **集成建议**:
   - `draft_scout_codec.py` 可直接配合 `0x92a6a0` (`draft.current_selection`) 与 `0xec9610` (`draft.select`)。
