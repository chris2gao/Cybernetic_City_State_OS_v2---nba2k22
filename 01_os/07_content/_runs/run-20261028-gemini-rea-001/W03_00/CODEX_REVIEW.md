# W03-00 Codex Review Guide

## 1. 重点审核内容
1. **防守位段粒度与原子性风险**:
   - `defense_18_codec.py` 实现了 18 字段在 12 字节内的位打包。
   - 审核注意：汇编指令 `0x14652c0` 采用 `mov rax, [rdx]` + `mov edx, [rdx+8]` 复制 12 字节，并非单条原子操作。若有其他并发写入，需要外层锁或写入保护。
2. **战术书上限与分区**:
   - `playbook_68_codec.py` 限制 68 槽。
   - 审核注意：在将 68 槽按 30/20/10/8 分割时，底层 Native 引擎只校验总数是否越界（`cmp eax, 0x44`），分区分配属于业务层校验。
3. **Gameplan 提交机制**:
   - 建议在未来需要触发比赛内战术生效时，在设置 `[Gameplan+0x0] = 1` 后，评估是否接入 Native 事件队列 `0x14af790`（事件 ID `0xf7ba8674`）。离线模式下直接写入内存结构即已满足读取要求。
