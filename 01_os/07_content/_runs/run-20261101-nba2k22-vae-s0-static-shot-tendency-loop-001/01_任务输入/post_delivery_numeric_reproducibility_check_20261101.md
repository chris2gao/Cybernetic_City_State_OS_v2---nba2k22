2. **最新快照挑选规则疑似错误**：
   - 本任务报告声明 `ROW_NUMBER() OVER (PARTITION BY player_id ORDER BY unit_id DESC)` 选最新快照。
   - `unit_id` 标识通常并不是按时间递增的顺序值。应使用现有 Stage01 `capture_units.observed_at` 及明确的成功/来源范围，再在同时间戳时按稳定ID决断；对于某一历史S0区间需要按当时可用的时间证据解释，不能倒推过往游戏场次当时数值。
   - 核查实际分析所用SQL是否真用了错误排序。如影响对象值、样本或回归，重算并发布有证据的更正；若未影响，展示前后对比确认。

3. **核心统计缺少可执行来源，而8/8测试几乎全是静态JSON断言**：
