## 三、2026-10-27 Human 范围纠正：原生统计读取 ≠ 自行计算篮球统计

**按Human当轮直接表达和原始A v1.9 的 Q31–Q33 后续限缩共同理解**：

1. PC22已提供的赛季累计、场均、职业统计、排名、奖项、Box、基础/高阶数据：**直接读取游戏原生可取得的文字/数字**，保留身份、赛季/阶段、口径、来源、采集时间，进入已定义容器并支持正确查询。不会以额外计算能力替代游戏权威。
2. 本第一大任务不开发独立累计得分/均值重算、排名重排、奖项再评选、预测、额外高阶分析引擎或每36分钟全面专项产品；不将独立篮球计算引擎列为阶段02研究前置或03数据库验收项。
3. `Q24` 的「赛季进行中/最终值」是**游戏实际观测值的时间及终态区分**，不是要求外挂重新累计；`S4/S6` 的研究对象只应是**实际Native字段、容器、阶段、来源及最终已生成状态**。
4. Native原始格式解码、已经有的显示转换，以及必须的数据库技术正确性对账可在其明确范围内保留；但**不得顺势扩展为新篮球业务统计能力**。已有 F-02 Box 的逐人/球队原生与canonical一致性判断仅作为限定的数据保真来源检查，不升级为全域赛季重新统计工程。
5. 之前阶段02接续说明的“下一项 S4/S6 赛季累计与定稿模型”用语**解释性修正**为：`S4/S6 游戏原生赛季统计、冠军/奖项与历史定稿的来源、字段和容器适配核销`。原先开放的 S1 Box 失败具体原因仍 `UNKNOWN`；不是新Reader或新增表的已证缺陷。
6. 原始A中的 `faithfully_reproduced_derived` 仅指有证据且**确实需要**的保真转换/个别游戏表示等价结果，不是对新计算项目的默示授权。该词与本次明确非目标存在解释冲突时，优先保守限定并触发Human修订影响分析，而非自选宽解释。

本次变更类别：`HUMAN_SCOPE_CORRECTION / incremental material information event`。**初步处理为恢复先前有效非目标边界**，不声明已经替换或重新批准原始A/现行A；如对现行A确需改文义，创建后继A候选并完成精确Human版本确认，历史Blob不可改。
