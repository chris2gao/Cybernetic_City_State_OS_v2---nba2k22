## 5. 技术发现与真正Native调用的独立准入门

```text
source hypothesis (game guide / UI question)
   → L1 typed metadata and actual instance source
   → L2 function and branch path [static evidence, no runtime implication]
   → L3 correct scene-dependent state change/consumer [same-mode evidence]
   → candidate callability [not execution permission]
   → check ABI + this + game thread + lifetime + transaction/callback dependencies
   → request Human precise test-save / action / object / allowed mode authorization
   → after approval: bounded controlled invocation and new native capture
   → complete affected-set compare and provenance/cleanup
```

当`L3`或ABI缺失，结论就停在`BOUNDED_UNKNOWN`；发现函数地址或静态反编译不等于已经找到可安全Native调用路径。对交易尤其必须将`validation`、`commit`和`events/indexes`分离，候选原生调用未证功能完整时保留外部模拟路线。
