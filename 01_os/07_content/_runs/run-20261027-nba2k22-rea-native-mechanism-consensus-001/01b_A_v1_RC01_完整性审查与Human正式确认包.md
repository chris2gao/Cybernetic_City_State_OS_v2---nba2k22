## 三、没有产生新的Human承重议题：模型自主给出的可逆判断

- 首枚徽章和首个教练UI设置的具体游戏名称/版本**由Codex在有真实来源可达时按最大证据信息增益选择**，并记录原因；Human批准的是选样深度而非固定一个名称。
- 机制图谱允许`L0-L3`的来源不完全，不能把`L2`函数地址视为`L4`安全调用。`L4`要有另获Human允许的隔离档实际代表调用与fresh Native readback；`L5`生产接口不属于本P0任务。
- 若外部游戏二进制可能使用无凭据或有著作权限制的内部源码/反编译成果，报告仅保存合法可审查的必要片段/指纹，不把商业游戏大段代码上传公共仓库。
- PoC的安全否定或有边界UNKNOWN属于**研究成果**，并不等价PoC成功；若Human拒绝/尚未授权实际调用则如实标`NOT_EXECUTED`，任务是否在研究结论足够时结束仍由Human确认。
- 整个EXE的REA/Ghidra静态分析已报告多次provider_timeout；后续Codex优先有界局部追踪，按新真实证据调整；不推断REA能直接把Windows游戏任意函数转换为可调用API。
