# REA 研究最终目标补充：可供AI决策的游戏机制知识 + 双执行路径

**Task**：`NBA2K22-REA-NATIVE-MECHANISM-DISCOVERY-01`；2026-10-27。**来源**：Human本轮明确补充，作为后续Stage03结果B的承重设计约束；不改写已正式批准的`A0-v1`/`A-v1-RC01`冻结Blob，不扩大当前P0的三代表机制研究退出门，也不授予任何真实游戏操作许可。

## 一、Human提出的最终产品方向

1. REA的逆向价值首先是**理解游戏本身真正如何运作**：理解AI机制、字段真实含义、规则约束、战术在游戏里的解释、条件与更新副作用，沉淀有证据可更新的**机制知识文档**，提供GM、教练、球员外部AI模型查阅和决策，使模型逐步能熟悉并操作NBA2K22游戏。不是单纯“找到可调用函数”。
2. **如证明能安全复用原生函数**来完成所需游戏行为，外挂的AI决策通过原生函数执行，尽量替代既有直接实时内存写入。
3. **如无法安全调用目标原生函数**，但已通过逆向理解了游戏原有机制、字段语义及正确生效条件，则保留此前**实时内存写入**执行路径，按照真实原生规则选择写什么、为什么写、怎样检查有效性，达到正确的游戏行为。绝不能因为原生调用失败就认为整个机制研究无价值。
4. 以上所有执行路径均受已收到的**“仅研究AI自主机制／AI与AI之间机制，不研究玩家确认与编辑机制”**这一Human约束；对玩家UI仅作必要只读观察，不当成外挂AI原生执行接口。

## 二、需求→结果模型B的可验收后果

### A. 对GM/Coach/Player可消费的机制知识库（Knowledge Track）

每张机制卡必须能让模型回答：**这是什么机制、什么对象和字段、现实游戏语义是什么、何时触发、哪些前置条件、游戏如何计算/处理、可能修改哪些相关状态、如何确认实际生效、哪些结论未证实**；附`GAME_BUILD/PC22/offline MyLEAGUE/AI_ACTOR`、Source/Evidence/函数路径/适用性/版本、反例、证据等级、最后观察时间、每个AI角色可读/可用标记。具体未知项如计算公式不能臆测。原始逆向证据与精炼角色文档分层，AI日常使用的文档必须包含可用动作语义、字段设置理由和限制，**不仅是IDA/Ghidra原始反编译碎片**。

### B. 外挂执行语义与可择后端（Execution Track）

外部AI提交的是**标准化领域意图**（例如`COACH_SET_DEFENSE_POE`、`GM_PROPOSE_TRADE`、`PLAYER_TRAIN_FOCUS`），并不是由语言模型任意拼函数指针/地址。统一语义层先确认游戏模式、AI参与方、目标对象身份、当前状态、业务条件、权限与安全约束，再选择经实证验证的执行后端：

- `NATIVE_FUNCTION`：在目标AI机制有证实的函数与合法ABI/this/线程/对象生命周期/副作用，并已得到该具体游戏动作Human批准的条件下，**优先**调用原生函数。成功要求与真实游戏状态及相关对象fresh读回一致，不能只看返回值。
- `VALIDATED_MEMORY_WRITE`：原生执行路径不可用、不可证明安全或不适用，**但**字段含义、值域、作用域、数据依赖、缓存/刷新与业务联动、必要的写后读回及失败处置都已有足够实机证据时，继续采用经验证的实时内存操作；任何旧DEV07/外部GM Reader或Writer都不能不复验直接被认作当前构建安全可写。
- `NO_SAFE_PATH`：无法证明原生调用**也无法证明实时写入安全/完整**，必须阻断并提供具体证据缺口，不许冒充已完成任务。
- `HYBRID`：在某些确有证据且可分离的场景中，原生动作加有限后处理写入可以作为未来Human批准的设计选项，但须对完整性和权限分别举证；不能作为绕过原生事务约束的默认方案。

**优先**不等于盲目调用原生函数；**内存兜底**不等于盲目写字段。行为以游戏内实际效果为准，强调持久化、缓存、事务/一致性、上下文和风险。

### C. 解释性行动规范与权限隔离

- 形成可供AI角色的`Mechanism Knowledge Card`、`Field Semantics`、`Action Contract`与`Execution Capability Matrix`：`可读/可推理/可建议/可执行/需Human许可/未证实`分开。
- 模型**自由熟悉与决策**不意味着无人监管地写游戏内存或修改受保护存档；真正操作须走既有OS、人类授权与可验证工具调用。AI人格可提出计划，执行器只执行经过校验和批准的类型化命令。
- `NativePath`和`MemoryWritePath`必须服务于**相同领域行为结果合同**，共用前置约束、预期业务影响和新鲜读回，而不是产生两套互相矛盾的游戏规则。
- 对“字段如何改变”“为什么调整战术”和“为什么选某个动作”的解释必须可溯源，可向AI角色暴露获准公开的信息，隐藏/内部Native字段不能因为研究可读就自动暴露给普通角色。

## 三、当前P0研究与长远完整知识体系的阶段边界

Human希望长期逐渐使外挂AI熟悉游戏所有有用机制；当前P0获得批准的`Q3=A`完成门仍是**M1一徽章、M2一教练策略、M3 AI-AI交易**三个代表机制有证据的结果及可行性结论、最多1–2个条件许可PoC。**不能因此变成“先逆向全游戏才恢复世界数据Stage02”**。B0本轮应设计**可扩展的知识与双后端合同**，未来大规模机制目录和生产执行器属后续独立获权项目。
