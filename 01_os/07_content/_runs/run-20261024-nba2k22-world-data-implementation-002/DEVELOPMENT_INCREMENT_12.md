# Increment 12 — annual refresh for historical records and awards

Human steering: “历史记录，各种奖项，我们采集的时候，每年刷新一次即可。”

The policy is implemented per Human-bound save, native game-season year and historical source family. The host calendar is irrelevant. `capture-records` and `capture-honors` acquire only small year controls when a successful live capture already covers that family/year, returning `already_refreshed` and the prior immutable unit. A SQLite insert trigger also rejects concurrent duplicate successful live annual units. Failed acquisitions remain retryable. Fixture replay does not consume a live period. Existing ordinary game/current-season capture remains unchanged. There is no scheduler or game action.
