## Corrections supported by the new metadata

**SeasonStats has 25 fixed elements.** Earlier research decoded only the current entry plus 20 history entries and stopped at the first empty marker. The new reader retains all positions and sparse references. Actual source classifications: 370 current-index candidates, 2,639 ordinary history-index candidates, **316 references after empty slots**, and 81,425 empty sentinels. Shared or unowned stat slots retain all source references; no arbitrary first owner or historical ordering is chosen.

**CompactYear is eight bits in both stat types.** The old seven-bit decode would wrap 2028+ back into the 1900s. The AG01D stat decoder and prototype TEAM-stat season-control readers now use the actual unsigned byte. Tests cover 127, 128, 200 and 255 source codes. This is a representation correction, not proof that the game supports every future season or a claim that a 100-season benchmark ran.

**UniqueId is +244 uint16; PreservedId is +760 uint32.** The previous +0x2F8 low16 field was a preserved identifier, not the field currently named UniqueId. Existing opaque canonical player keys and old history are retained. Exact current-roster name/preserved-ID matches, with unique current source IDs, append **461 current UniqueId link observations**. They do not certify cross-session lifetime identity or authorize destructive key rewriting. Role cards now show the two observed IDs and the legacy field semantics.

**Five potential-related native fields occupy four intervals:** `[785,786)`, `[880,882)`, `[930,931)`, `[1089,1090)`. These cover OriginalPotential, MinPotential, MaxPotential, PreviousPotentialRaw and PotentialRaw. Public full-family acquisition now physically skips every interval. The native source reader uses only public name, identity, team pointer and reference projections, verifies the exclusion intervals against current metadata, and acquires one separately labeled sanitized public-family privacy probe. Public decoding is tested to be independent of every excluded byte. Prior owner artifacts remain restricted historical material; their old main-byte-only physical exclusion claims are not retroactively broadened. No new private values enter role facts.
