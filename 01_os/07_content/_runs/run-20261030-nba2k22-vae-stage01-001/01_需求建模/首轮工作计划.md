# VAE Stage01 首轮工作计划（候选，不是执行授权）
## 任务定位
VAE独立于D1–D5，按照同一OS Workflow及通讯/上下文机制管理；MyLEAGUE底层为产品目标，当前MC存档是实际验证载体。实验结果由NBA2K22原生比赛/模拟引擎产生。
## 首批开发原型（纵向切片，不先追求全量）
1. **配置与对象基线**：优先确定当前实际运行Profile的字段、模式、USER/CPU侧、存档实例和PE版本，区分当前实测与静态建议值。
2. **问题—假设—试验合同**：为一个游戏表现问题确定篮球依据、改动对象与原值、技术路径、效果主指标、副作用、观察窗口和恢复策略。
3. **技术读回**：通过已验证REA能力或Human批准的原生UI调整，分开记录参数写入、UI一致性、保存重载和真实比赛消费证据。
4. **竞技观察**：Human自然游玩；只读采集可得的单场/球队/球员统计与现场观察，分开对待3D和Calendar Sim，允许观察不足。
5. **经验与D系列反馈**：追加记录每轮证据、失败及修订，同时登记与D1信息需求、D2读取、D3采集、D4信息服务和D5执行闭环相关的实际缺口。
