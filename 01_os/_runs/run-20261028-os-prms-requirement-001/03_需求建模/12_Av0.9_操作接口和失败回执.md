# OS-PRMS A-v0.9 操作输入输出与失败合同（Q49=B）

**候选逻辑接口，不是已实现API。** 所有动作均要求role/task/version/证据语义，不预定REST/CLI函数签名；阶段02/03核实适配。

## 共用逻辑输入/输出

输入：`operation_id`（幂等键）、`actor_role_id`、`assignment_ref`、`expected_version`、`payload`、`source_refs`。
输出：`status`、`result_ref`、`authoritative_commit_sha`（成功时）、`receipt_ref`、`conflict_ref`、`retry_safety`、`next_action`、`observed_at`。

公共结果候选：`SUCCESS`、`ALREADY_APPLIED`、`REJECTED`、`STALE_OWNER`、`VERSION_CONFLICT`、`AUTHORITY_MISSING`、`PARTIAL_STAGED`、`PUBLISH_NOT_CONFIRMED`、`EXTERNAL_EFFECT_UNKNOWN`、`UNVERIFIED`。失败不得把“可能成功”写为成功。

## 关键操作合同

| 操作 | 输入/前置条件 | 成功状态与回执 | 拒绝/冲突/未知/部分失败 |
|---|---|---|---|
| 注册模板 | template_id、version、OS角色职责、来源规范 | 新版本及Registry索引回执 | 重复同版本且内容不同=冲突；缺来源=拒绝 |
| 创建岗位实例 | 模板版本、项目、工作岗位、幂等键 | 稳定role_id、初始CURRENT与索引的有效版本 | 同ID重复且一致=ALREADY_APPLIED；非一致=VERSION_CONFLICT；部分初始化不得启用 |
| 绑定任务 | role_id、task_id、Human授权证据 | Assignment和权限边界 | 无新任务授权=AUTHORITY_MISSING；旧岗位任务授权不可复制生效 |
| 自动接管 | role_id、new_session_id、expected_owner_version | GitHub权威读回owner_epoch后SUCCESS；旧凭据失效 | 冲突=VERSION_CONFLICT；断网/读回失败=UNVERIFIED，不自称成功 |
| 追加事件 | event_id、source refs、事件类型和事实类别 | 追加记录及来源commit | 重复ID相同内容=ALREADY_APPLIED；不同内容=冲突，原历史不覆盖 |
| 提炼/修订经验 | 原始证据IDs、内容、适用范围、反证 | 经验卡版本和stale关系 | 缺事实来源=REJECTED；意见不自动发布为规范 |
| 创建检查点 | 角色、任务、触发、依赖、未知外部操作 | 候选+完整校验后发布CURRENT | 中途失败=PARTIAL_STAGED；保留最后有效CURRENT |
| 恢复岗位 | role_id、task、可验证来源commit | 恢复包、当前状态、任务历史、证据及接任回执 | 不具备源读回=UNVERIFIED；未知外部结果禁止自动重放 |
| 检索记忆 | 角色/任务/主题/时间/状态过滤与分页 | 结构化摘要、版本、证据、stale、detail_ref、next_cursor | 缺源证据=标注evidence_missing；不暗示可信 |
| 正式共享知识发布 | 候选经验、证据、OS批准引用 | 正式知识版本和发布回执 | 未审批=AUTHORITY_MISSING；其他角色可读不等于正式发布 |
| 全量复制岗位记忆 | source_role、target_role、source_commit、全量源清单 | 每项内容真实副本、完整性回执、风险报告、目标独立CURRENT | 缺项=PARTIAL_STAGED；不把源CURRENT/任务权变成目标当前值 |
| 删除活动实例入口 | role_id、当前任务授权、历史保存策略 | 活动入口删除回执，历史索引仍可查 | 未授权拒绝；不得声称Git旧历史已物理擦除 |
| 核心设计升级 | 经Human确认的03设计B、目标规划入口、发布授权 | 核心规划规范的提交SHA与读回 | 当前阶段不执行；不能将设计版宣称为运行时 |

## 用例示意（不是实际JSON协议）

`takeover(role=architect_os, session=new_gpt, expected_owner=17)` → `SUCCESS(owner_epoch=18, github_commit=<verified>)`；旧会话使用epoch17提交 → `STALE_OWNER(no_current_update)`。

`copy_all(source=architect_os, target=planner_2k, source_sha=X)` → `SUCCESS(copy_manifest, all_items_verified, risk_report, target_current_new)`。任一源项缺失 → `PARTIAL_STAGED`，不能把部分副本登记为全量完成。

## Q34=B 故障恢复原则

只允许重试**可证明幂等且尚未有效发布**的步骤。所有权或版本冲突、外部副作用结果未知、需要新的Human语义裁决时停止报告。实际跨文件原子性及工具能力留EVQ，不能提前宣称可用。
