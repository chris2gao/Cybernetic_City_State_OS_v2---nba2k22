1. **原样保留**——认为 6,285 字节买的是"生命周期枚举纪律 + 大任务编排"这两条行为规则，
   它们的价值本来就不由枚举字节度量；且枚举收益要等到有 run 被判为终态才会出现。

   这会显著降低 6,285，但也降低这条规则被真正读到的概率。
3. **拆开判定**——`开发入口 §5` 的 lifecycle 枚举强制（+14 行）是根因修复，
   没有它终态永远是 0、归档永远不可能发生；这一条与工作集工具的叙述可以分别取舍。
