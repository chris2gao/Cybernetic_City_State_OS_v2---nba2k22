- model routing 是独立 `03_mechanisms` capability，workflow 不复制 model catalog；
- mechanism 自身描述职责、loader、disk dependencies、failure surfacing；
- routing input 至少有 task/role/risk/task_shape/required_capabilities/Human availability；输出含 model + surface + parameter profile + basis + evidence + limitations + `authority: routing_only`；
- registered model 默认 available；Human unavailable 排除、restore 恢复；不存在自动 quota/cost availability scorer；
- model 与 product surface 分离；current facts 带 source/ref、verified_at、invalidation condition/confidence；
- parameter surface-specific；API-only reasoning 枚举不能冒充 Web/Desktop 参数；
- project observation 与 vendor facts 分离；diagnostic/anecdotal evidence 不能形成 hard qualified/unqualified route；
- 能表达当前 ChatGPT Plus Web、Codex Desktop、Claude Code Desktop、Gemini Web、Antigravity，并保留 unknown/entitlement 边界；
- `开发入口与单窗口任务规范_v1.md` §7.1 最终只保留稳定 preflight + canonical pointer，不再长期内嵌 price/volatile model catalog；
- §8、§9、publisher authority、T3/protected-action 控制不得削弱；
- registry / boot / execution-loader pointers 与 mechanism version 一致；缺文件、断 pointer、重复 key、缺 freshness/source 字段 fail closed；
- routing decision primitive 不包含 token/cost/quota 优化、自动 fallback 链或自动 entitlement crawler。
