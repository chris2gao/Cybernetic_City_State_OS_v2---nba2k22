## 7.1 模型路由约定

每个正式任务必须在开工前执行一次 model-routing preflight：读取
`01_os/03_mechanisms/model_routing/` 的路由契约与活动目录，得到 model + surface +
parameter profile，并把结果写入任务包的 `executor_profile`。

- 已登记候选默认 available；账户当前 availability 只由 Human override 决定，
  机制不自动探测额度。
- 路由输出的 `authority: routing_only`，不授予任何发布、文件系统或安全权限。
- 活动模型目录、参数档位与推荐路由全部由上述机制承载，本入口不再内嵌。

## 8. 测试与证据标准

正例、负例、边界例及退出码；基线/候选对照；changed paths 与 allowlist 精确比对；
不可观测指标写 `not_observable`；tool crash fail closed。

## 9. 独立审核与 Human gate

实现窗口与最终审核窗口必须是不同会话。`T2_semantic`、`T3_high_risk`、master 接入
或经历修正轮次的任务，派单会话不得兼任最终审核；优先不同模型族。

`T3_high_risk` 按 blast radius 判定，不按剩余自由度判定。

发布权限本身见 `01_os/05_registry/repository_publisher_authority_v1.yml`。
发布传输门禁见本文件 1.1 的 `publication_transport` 矩阵。

## 11. 停止条件与修正预算

需要新增授权或 action-bound Human gate 的 publication / protected action，
以及证据不能支撑声明时，停止写入并回传。
