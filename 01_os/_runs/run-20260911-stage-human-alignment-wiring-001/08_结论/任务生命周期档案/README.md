## 这不是启动面

本目录是既有 W6 run 的任务证据，不是新的常驻启动面。

- 没有任何程序加载它，没有任何 boot 清单引用它，它不在任何 validator 的读取路径上。
- **不要默认预载**，理由与 `01_os/_runs/**` 相同：它会随任务增长，把它塞进开局上下文
  只会挤掉真正被触发的材料。
- 因此它**不进 `01_os/05_registry/`**。那份 registry 回答"谁加载、怎么被发现、失败何时
  显形"，而这里的答案分别是"没有人、不需要、不适用"。给一个没有加载者的目录登记 registry
  条目，等于声称它是运行系统的一部分——那恰好是本目录第一份文件记录的那类错误。

所有权沿用 `CORE_MANIFEST.yml` 对 `01_os/_runs/` 的既有声明，不增加新的所有权根。

## 放什么

本次任务值得跨窗口保留的东西：

- 任务的**根因分析**与**失败模式**，尤其是那些会重复出现的；
- **交接记录**：下一位执行者必须知道、但不在代码里的东西；
- **待验证假说**：已经想清楚、但尚未用实验证伪过的判断。

## 不放什么

- 其他任务的工作记录——应进入各自的 `01_os/_runs/<run>/`。
- 机制契约、schema、validator——那些属于 `01_os/**`，本目录不得成为它们的第二份真相源。
- 任何声称自己是规则的东西。本目录的文件**描述发生过什么、以及我们据此相信什么**，
  它们不构成对任何执行者的约束。要变成约束，得先进 `01_os/**` 并被机制消费。

## 命名

`<YYYYMMDD>_<主题>_<类别>_v<n>.md`，类别取 `根因分析` / `交接` / `待验证假说` 之一。
