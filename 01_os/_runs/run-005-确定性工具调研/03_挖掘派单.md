我们在建一套人机协作工作流，原则是：
**理解与决策交给大模型，确定性工作交给外部工具。**

现在需要找**能被 agent 驱动的开源工具或 skill**，来承担下面 17 项确定性操作。

请对每一项回答：**有没有现成的东西、能不能被程序驱动、接入成本多大。**

#### 17 项操作

| # | 操作 | 输入 → 输出 |
| :-- | :--- | :--- |
| 1 | 结构化对象的 schema 校验与缺失字段判定 | 对象 → 缺哪些必填、哪条约束不满足 |
| 2 | 把校验错误转成排序后的追问 | 校验错误 → 按影响度排序的问题列表 |
| 3 | 两份清单的重合度与总体规模估计 | 两份清单 → 重合数、capture-recapture 估计 |
| 4 | **循环报道剥离** | 一批引用 → 追溯首发出处，合并重复来源 |
| 5 | **形态分析的交叉一致性剔除** | 多维参数矩阵 → 剔除互斥组合后的有效候选集 |
| 6 | **竞争性假设分析（ACH）矩阵计算** | 假设×证据矩阵 → 不一致计分、诊断性排序 |
| 7 | 敏感性分析 | 上述矩阵 → 结论对单条证据的依赖程度 |
| 8 | 论证结构中的"孤立主张"检测 | 主张—证据关系 → 有无未挂证据的主张 |
| 9 | RDF 图的形状约束校验 | RDF 图 + SHACL → 违规节点 |
| 10 | 测试溯源校验 | 测试集 → 每条测试是否挂了被测对象与判据来源 |
| 11 | **变异测试** | 代码 + 测试 → 测试套件的缺陷捕获率 |
| 12 | 约束可满足性求解 | 约束集 → 有无可行解、矛盾在哪 |
| 13 | **原子级事实支撑度度量** | 一段主张 + 知识源 → 各原子事实被支持的比例 |
| 14 | 覆盖关系检查 | 两个集合 + 映射 → 哪些元素未被覆盖 |
| 15 | 多次采样结果的筛选 | N 次输出 + 判定条件 → 哪些通过 |
| 16 | **prompt / skill 的行为评测** | prompt 或 skill + 用例 → 是否达到期望行为 |
| 17 | 测试运行与可重复性核验 | 测试 → 结果；同输入是否同结果 |

**加粗的六项是我们认为最难找到现成方案的**，请重点回答。
如果确实没有，直接说没有——**"没有"是有用信息**。

#### 关于"能否被 agent 驱动"

这是**最关键的筛选条件**。我们的场景是程序或 agent 自动调用，
**只有图形界面的工具对我们价值极低**，即使功能再好。

如果某项只有 GUI 方案，请说明，并指出有没有可编程的替代路径。

#### 关于 "skill"

除了传统工具，我们也想知道有没有**打包成 agent 可安装能力**的形式——
Claude Skills、MCP server、各类 agent 框架的插件等。这类东西接入成本最低。
