## 4. 分词器暴露的两条合同要求

这两条不是缺陷，是**引用图 validator 必须满足的输入约束**：

1. **文件名含空格。** `chatgpt - deep-research-report.md` 这类命名在语料中真实存在。
   任何按空白切词的引用抽取都会静默截断，且截断结果**看起来像一条断链**。
   合同必须规定引用的定界方式（引号、反引号或显式字段），不能靠空白。
2. **路径可带 `#anchor`。** 例：`.ai/communication_compliance/README.md#release-binding`。
   合同需规定 anchor 是否属于引用目标的一部分。

**这两条正是上一份 inventory 产生假故障的机制。** 记录在此，使其可被防住。
