## 不再让 Human 逐条审的历史噪声

- 派单、审核、完成指针、前台控制分支：可作背景证据，不独立构成功能增量。
- 10 号 check-jsonschema：唯一未合入提交的补丁与 master 等价；对应能力已经有 canonical 入口。
- 17、23、68 号：已验证分别是 18、24、67 号的祖先，不重复推荐。
- 21 号 Cosmic Ray：master 已有 fail-closed WSL canonical wrapper；旧 native candidate 属另一平台方案，不应当成该功能完全遗漏。
- 阶段协同推演早期阶段、P1/P2/P3–P7 和通讯系统旧候选：当前 master 已有相应机制/执行入口；文件不同不等于这些旧版本仍需再合入。
- 58 号 Human alignment 推演前驱：W6 已明确冻结，末轮 CHANGES_REQUIRED，不恢复其旧实现来覆盖新 W6。
- 授权码、模型注册的旧治理或回执分支：不因提交未成祖先就恢复旧规则；只在明确发现当前 catalog/规则缺项时才值得提取。

本轮没有把其余历史分支宣布为“永久无价值”。完整 68 组与 1197 个独立提交记录仍可查；
但没有发现足以将它们提升到上述功能短名单的独立证据，因此不让它们占用本轮合并决策。

## 给其他模型的最小判断材料

1. 先读当前 master 的入口与本文件，不默认重载全部历史。
2. 根据上表精确 SHA 到线上候选读取实现与历史结论，而不是只看 README 的 Verified / commit subject 的 integration 字样。
3. 区分“master 缺少代码”“值得采用”“验收已完成”“可以集成”四个不同结论。
4. Human 选择后再按时间及真实 Git 依赖整合；此次清单不授权任何额外分支合并。
