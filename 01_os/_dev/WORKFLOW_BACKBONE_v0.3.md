# 工作流骨干 v0.3

状态：活动。取代 v0.2。

## 承重关系

```text
需求 → A → 证据 → B → 测试 → 步骤 → 执行/验证循环 → A 满足
```

- 阶段一通过追问和 Human 同义确认形成 A。
- 阶段二收集、核实和提炼可支持或推翻 A 的证据。
- 阶段三用 A 与证据建立 B；B 同时描述结果形态和有证据锚点的实现方法。
- 阶段四的被测主体来自 B，通过判据来自证据。
- 阶段五从 A、证据、B 与冻结测试拆步骤。
- 阶段六把判断留给模型，把可确定执行交给 skill/工具。
- 阶段七执行测试并核对实现对 B 与证据，不只看绿灯。

任何阶段发现上游模型失效都可回流。B 实现且证据派生测试通过，等价于 A 被满足。
