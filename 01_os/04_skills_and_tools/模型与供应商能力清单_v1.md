# 模型与供应商能力清单 v1

本文件只记录可供 Human 做任务路由时参考的产品、环境与能力，不定义系统角色，
也不授予任何权限。

**供应商名称、模型名称、订阅等级、工具可用性或 capability 均不产生 authority。**
执行者、审核者或决策者角色只能来自 current task、task packet 与当前 Human authority；
实际能力仍须在每次任务中按当前环境重新确认。

以上是 capability inventory，不是默认加载表、端点卡、任务分配或授权登记。
产品能力、版本和可用性变化时，以 current task 的真实探测结果为准。
